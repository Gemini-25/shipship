# 새 엔진 설계서

가지 `claude/engine-rewrite` · 2026-10-16 시작. 옛 게임은 `claude/elegant-ritchie-04p1tr`에 그대로 있다.

## 0. 왜 새로 짜나

지금까지의 사고는 **대본**이었다. '냉매 누출' · '운석우' · '전선 화재' 같은 사고 목록이 있고, 사고마다 무슨 일이 벌어지는지를 사람이 짰다.
그래서 사고가 늘 비슷하게 흘러가고, 사고끼리 서로 엮이지 않으며, 사고를 하나 넣을 때마다 규칙을 새로 써야 했다.

새 엔진은 거꾸로 간다. **세계의 법칙**(기체 · 열 · 화학 · 구조 · 전기 · 몸 · 마음)을 탄탄히 세우면
사고는 그 법칙이 만나는 곳에서 **저절로** 생긴다. 낡은 냉각관이 새고, 새는 냉매가 전선 곁 칸에 고이고, 그 칸이 뜨거워지고,
누가 문을 닫아 연기를 가두고, 주컴퓨터가 미래를 돌려 보고 그 방을 비우기로 한다 — 이 사슬을 아무도 짜지 않았다.

그리고 그렇게 생긴 일을 **잘 보여 주는 것**이 재미의 핵심이다. 연출 엔진이 무엇이 흥미로운지 알아보고,
카메라 · 확대 · 시간 · 다시보기를 알아서 다룬다.

## 1. 함장이 정한 것

| 질문 | 답 |
|---|---|
| 목표 | 창발성 · 사실감과 깊이 · 규모와 성능 · 코드 정리 — 넷 다 |
| 세우는 방식 | **새 코어를 처음부터** (`engine/`). 화면은 Godot 유지 · 새로 짠다 (도트 화가 · 효과음 · 음악은 다시 쓴다) |
| 사고 | **모두 엔진 원인에서**. 사고 목록이 없다. 이야기꾼은 원인(낡은 부품 · 다가오는 파편)만 심는다 |
| 가혹함 | 물리는 진짜 그대로. 기본은 **아슬아슬하게** (이야기꾼 단계에 따라 조절 — 현실 그대로까지) |
| 우주 | **물체 · 궤도 · 충돌**. 파편 · 운석 · 다른 배 · 행성이 실제로 움직이고 부딪친다. 별 활동 · 방사선 · 햇빛 |
| 물리 | **칸 단위 격자 · 평면 하나** (지금 칸 크기). 기체 · 압력 흐름 · 열(전도 · 복사) · 구조(하중 · 충격) · 액체 · 물체 운동 |
| 화학 | **물질 · 반응식**. 원소가 보존된다 |
| 망 | **회로 계산**. 과부하 · 합선 · 발열 · 전선 화재가 저절로. 배관은 압력 · 유량 · 새는 이음매 |
| 사람 AI | **층을 나눔** + **점수 + 단계 계획**. 본능 → 욕구 · 감정 → 목표 → 계획 → 동작 · 믿음과 오해 · 감정 · 기억 · 성격과 관계 |
| 주컴퓨터 | **미래를 돌려 보고 고름** (세계를 복제해 안마다 몇 분 앞을 실제로 돌림) |
| 함장 | **관전 + 방침 + 가끔 큰 결정** (주컴퓨터가 정하기 어려운 딜레마만 묻는다) |
| 규모 | 배 한 척 60~100명 · 60프레임 · **결정론을 지키며 여러 코어** |
| 언어 모델 | 쓰지 않음 |
| 더 넣을 엔진 | 낡음 · 고장 · 소리 · 생물 · 행성 표면과 날씨 — **비슷한 것은 묶어서** (엔진이 너무 많지 않게) |
| 연출 | **완전 자동 감독**. 함장이 손대면 잠깐 양보하고 다시 맡는다 |
| 하이라이트 | 위험과 아슬아슬함 · 사람의 이야기 · 원인 사슬 · 처음과 드문 일 |
| 시간 | **긴장에 따라 자동** (조용하면 빨리 · 조짐에 느리게 · 결정적 순간 느린 화면) |
| 다시보기 | **조짐부터 되감아 다시보기** |
| 화면에 엔진 속 | 기본은 **눈에 보이는 것만**. 기체 · 열 · 연기 칸 · 사람 머릿속 · 원인 사슬 · 주컴퓨터의 상상은 **화면 설정**으로 켠다 |
| 데이터 | 물질 · 반응 · 재질 · 설비 · 활동은 **데이터 표** (`engine/data/*.json`) |
| 시험 | **법칙 시험**(보존 · 대칭 · 결정론 · 경계) + **규칙 시험** + **재미 측정기** |
| 과정 | **층마다 돌린다**: 설계 → 법칙 시험 → 구현 → 관찰 장면 → 재미 측정 → 커밋 |
| 순서 | **아래 층부터 깊게** |
| 첫 시험 배 | **옛 배 도면 그대로 가져오기** (이미 승인된 배 — 새 설계 승인이 필요 없다) |
| 옛 기능 | 행성 시스템을 포함해 차례로 새 엔진 위에서 다시 살린다 (사람 이야기 · 주컴퓨터 성격 · 기술 · 임무 …) |
| 시험 돌리기 | 엔진을 다 만들 때까지 옛 장면 시험은 돌리지 않는다. 새 엔진은 법칙 시험 · 규칙 시험만 |

## 2. 전체 구성 — 엔진 13개, 네 묶음

후보 18개(물리 · 화학 · 우주 · 망 · 몸 · 감각 · 이동 · 사람 AI · 로봇 AI · 주컴퓨터 · 제작 · 사회 · 이야기꾼 · 연출 ·
낡음 · 소리 · 생물 · 행성 날씨)를 **같은 상태를 다루는 것끼리** 묶었다.

```
 이야기   ⑬ 연출(감독)        무엇이 흥미로운가 · 카메라 · 확대 · 시간 · 다시보기 · 화면 겹침
          ⑫ 이야기꾼          긴장 곡선 · 원인 심기 (낡은 부품 · 파편 구름 · 손님 배)
 ─────────────────────────────────────────────────────────────────────────────────────
 마음     ⑪ 일과 물자         일감판 · 생산 사슬(재배→수확→조리→식사 · 원료→정제→부품) · 막힌 마디
          ⑩ 주컴퓨터          센서 → 믿음 → 안 → 세계 복제로 미래 돌려 보기 → 고름 → 설명 · 배움
          ⑨ 사회              관계 · 소문(믿음 전파) · 파벌 · 회의 · 문화 · 세대
          ⑧ 마음              사람 · 로봇 · 드론: 감각 → 믿음 → 감정 → 목표 → 계획 → 동작 · 기억 · 성격 · 이동 · 길찾기
 ─────────────────────────────────────────────────────────────────────────────────────
 세계     ⑦ 생명              몸(숨 · 체온 · 영양 · 물 · 상처 · 병) · 의료 · 작물 · 미생물 · 곰팡이 · 동물
          ⑥ 망 · 장치         전기 회로 · 배관(물 · 냉매 · 덕트 공기) · 데이터 · 기계(부품 · 마모 · 고장)
          ⑤ 바깥 세계         우주 물체 · 궤도 · 충돌 · 별 활동 · 방사선 · 햇빛 · 행성(중력 · 대기 · 날씨 · 땅)
          ④ 구조 · 물체       벽 · 외판 · 골조: 하중 · 충격 · 피로 · 부식 · 열 약화 · 구멍 / 물건 · 사람의 밀림 · 날림
          ③ 장(場) 물리       칸 격자 위의 기체 · 압력 흐름 · 바람 · 열 · 액체 · 소리 · 빛 · 냄새 · 방사선량
 ─────────────────────────────────────────────────────────────────────────────────────
 바탕     ② 물질              물질 표 · 반응식 표 · 재질 표 · 혼합물 연산 · 원소 보존
          ① 기반              시계 · 단계 실행 · 결정론 병렬 · 난수 갈래 · 데이터 표 · 찍기/되살리기/복제 · 원인 · 사실 흐름
```

묶은 것:
- **소리 · 빛 · 냄새 · 방사선량** → ③ 장 물리. 모두 '칸 격자 위에서 퍼지는 것'이다. 냄새는 기체의 미량 성분이다.
- **낡음 · 고장** → 벽 · 외판은 ④ 구조, 기계 부품은 ⑥ 망 · 장치. 둘 다 '상태가 쌓여 한계를 넘으면 부서진다'는 같은 규칙(피로 · 부식 · 마모 · 열)을 쓴다.
- **행성 표면 · 날씨** → ⑤ 바깥 세계. 행성은 우주의 한 물체이고, 착륙하면 격자의 바깥 경계가 '진공' 대신 '그 행성의 대기 · 날씨'가 된다.
- **생물** → ⑦ 생명. 사람 몸 · 작물 · 미생물 · 동물은 같은 규칙(칸의 온도 · 습도 · 기체 · 영양을 읽고 자라거나 앓는다)을 쓴다.
- **감각 · 이동 · 로봇/드론 AI** → ⑧ 마음. 감각은 장(③)을 읽어 믿음을 만드는 마음의 입구이고, 로봇 · 드론은 감정 대신 상태를 가진 같은 마음이다.

## 3. 엔진 사이의 약속

1. **아래는 위를 모른다.** ③ 장 물리는 사람이 있는지 모른다. 위는 아래의 상태를 **읽기만** 하고, 바꾸고 싶으면 **요청**을 낸다
   ("이 칸에 산소 0.4몰을 넣는다" · "이 문을 연다" · "이 칸에 열 2kJ"). 요청은 정해진 단계에 한꺼번에 적용된다.
2. **한 걸음 = 1틱 = 게임 2.4초** (한 시간 1500틱 — 옛 게임과 같은 빠르기라 도트 움직임 · 소리를 그대로 쓴다).
   엔진마다 도는 주기가 다르다:

   | 주기 | 엔진 |
   |---|---|
   | 매 틱 (2.4초) | 이동 · 위험 본능 · 압력 흐름 · 문 · 충돌 · 연출 |
   | 5틱 (12초) | 확산 · 열 · 반응(불) · 액체 · 감각 · 판단 · 회로 |
   | 25틱 (1분) | 몸 · 구조 피로 · 배관 · 일감 · 주컴퓨터 계획 |
   | 1500틱 (1시간) | 작물 · 미생물 · 사회 · 경제 요약 · 이야기꾼 |

3. **한 틱의 단계** (순서 고정 · 같은 단계 안에서는 서로의 결과를 읽지 않는다 — 그래서 병렬로 돌릴 수 있다):

   ```
   1 바깥     우주 물체 움직임 · 충돌 판정 · 별 활동 · 행성 날씨
   2 감각     장을 읽어 마음마다 '알게 된 것'
   3 판단     마음 · 주컴퓨터 · 일감 → 요청
   4 요청     요청을 적용 (문 · 밸브 · 스위치 · 물건 · 사람의 동작)
   5 망       회로 · 배관 · 장치 공정 (장치는 칸에 기체 · 열을 넣고 뺀다)
   6 화학     칸 · 탱크 · 몸의 반응 (불 · 부식 · 호흡은 생명에서)
   7 장       압력 흐름 · 확산 · 바람 · 열 · 액체 · 소리 · 빛
   8 구조     하중 · 충격 · 피로 · 구멍
   9 생명     몸 · 작물 · 미생물
   10 기록    사실 · 원인 정리 · 역사
   11 연출    관심 점수 · 카메라 · 시간 · 다시보기 고리에 찍기
   ```

4. **결정론.** 같은 시드 · 같은 입력이면 1코어든 8코어든 바이트까지 같다.
   - 칸 계산은 '이전 값만 읽어 새 값을 쓴다'(두 버퍼). 나누는 덩어리 수는 코어 수와 상관없이 고정이고, 합은 덩어리 순서대로 더한다.
   - 난수는 **갈래**로 나눈다 (엔진 · 사람 · 칸마다 따로 — 한 곳에서 난수를 하나 더 써도 다른 곳이 흔들리지 않는다).
   - 순서가 정해지지 않은 사전을 돌며 상태를 바꾸지 않는다. 같은 때 일어난 일은 번호 순으로 처리한다.
5. **원인.** 상태를 크게 바꾸는 모든 것에 **원인 마디**를 붙인다 (이 불은 이 합선에서, 이 합선은 이 냉매 누출이 적신 전선에서).
   원인 마디는 '무엇 · 어디 · 언제 · 부모 원인'이다. 연출 엔진의 원인 사슬 · 사고 조사 · 사람의 믿음이 모두 이걸 읽는다.
6. **사실 흐름.** 엔진은 일어난 일을 **사실**로 내보낸다 (종류 · 어디 · 언제 · 누구 · 크기 · 원인). 사실은 엔진의 바깥으로 나가는 유일한 소식이다.
   마음은 사실을 **직접 읽지 않는다** — 장(소리 · 빛 · 냄새)이나 눈으로 닿은 것만 안다. 사실은 연출 · 기록 · 시험이 읽는다.
7. **데이터 표.** 물질 · 반응 · 재질 · 설비 · 활동 · 성격은 `engine/data/*.json`. 코드에는 법칙만 있다. 표는 읽을 때 검사한다 (반응식의 원소가 맞는지 등).
8. **찍기와 복제.** 세계 전체를 바이트로 찍고 되살릴 수 있다 (사람 · 칸 · 망 · 원인까지). 주컴퓨터의 미래 돌려 보기 · 다시보기 · 되감기 · 저장이 모두 이것이다.
   찍기는 칸 배열을 통째로 복사하므로 빠르다 (목표: 100명 배 한 번 찍기 5ms 아래).

## 4. 엔진별 설계

각 엔진: 하는 일 · 상태 · 법칙 · 읽는 것/요청 · 데이터 표 · 법칙 시험 · 성능 목표.

### ① 기반 (`engine/ShipEngine/Base`)
- **시계**: 틱 번호 · 게임 시각 (1틱 2.4초).
- **단계 실행기**: 엔진을 (단계, 주기, 순서)로 등록 → 틱마다 그 틱에 돌 엔진을 단계 순서대로.
- **결정론 병렬 `Par`**: 줄 덩어리 단위로 나눠 돌린다. 덩어리 크기 고정 · 합산 순서 고정. 코어 수를 바꿔도 결과가 같다(법칙 시험).
- **난수 갈래 `Rng`**: 64비트 시드에서 이름 · 번호로 갈래를 낸다 (예: `rng.For("구조", 칸번호)`).
- **데이터 표 `Data`**: 내장 자원 JSON → 형 있는 표. 읽을 때 검사.
- **찍기 `Snapshot`**: 엔진마다 `저장(쓰개)` · `읽기(읽개)` — 정해진 순서로. 지문(해시)은 그 바이트의 FNV-1a.
- **원인 `Causes`**: 마디 목록 (번호 · 종류 · 글 · 칸 · 틱 · 부모들). 오래된 마디는 사슬이 끊기지 않게 요약해 줄인다.
- **사실 `Facts`**: 틱마다 쌓이는 사실 목록 (고리 버퍼 · 연출이 읽는다).

### ② 물질 (`Matter`)
- **물질 표** (`substances.json`): 이름 · 화학식(원소 수) · 몰 질량 · 상(기체 · 액체 · 고체 · 연무) · 정적 몰 비열 ·
  끓는점 · 녹는점 · 증발열 · 독성(무엇을 얼마에서) · 냄새 · 보이는 색.
- **반응식 표** (`reactions.json`): 반응물 · 생성물(몰) · 반응열(kJ/몰) · 일어나는 최저 온도 · 빠르기(아레니우스식 단순형) · 촉매 · 조건.
  v1: 호흡 · 광합성 · 고분자 연소(완전 · 불완전) · 셀룰로스 연소 · CO 연소 · 수소 연소 · 메탄 연소 · 전기분해 · 사바티에 ·
  철 부식 · 수산화리튬 CO₂ 흡수 · 암모니아 분해 · 오존 생성(전기 불꽃) · 오존 분해 · 부패(H₂S).
- **재질 표** (`materials.json`): 강철 · 알루미늄 · 티타늄 · 유리 · 고분자 · 복합재 · 구리 · 세라믹 — 밀도 · 비열 · 열전도 · 강도 · 피로 한계 ·
  녹는/타는 온도 · 이루는 물질 (강철 = Fe … 그래서 녹이 슨다 · 고분자 = (CH₂)ₙ … 그래서 탄다).
- **혼합물 `Mix`**: 물질별 몰 수. 칸 · 탱크 · 몸 · 저장고가 모두 혼합물. 더하기 · 빼기 · 비율로 떼어 내기 · 반응 · 열량.
- **법칙 시험**: 반응식마다 원소(C · H · O · N · …)가 같다. 반응을 아무리 돌려도 닫힌 혼합물의 원소 총량 · 에너지(반응열 포함)가 같다.

### ③ 장 물리 (`Field`)
칸 = 바닥 1m × 1m · 천장 2.5m → **칸 부피 2.5m³** (1기압 21℃에서 공기 약 104몰).

**기체** — 칸마다 성분별 몰 수 · 내부 에너지. 압력 = 몰 수 × 기체 상수 × 온도 / 부피.
- **구역**: 막힘없이 이어진 칸들(열린 문 포함)은 한 구역이다. 실제로 압력파는 30m 배를 0.1초에 건너므로, 한 틱(2.4초) 안에 구역의 압력은 고르게 된다.
  → 구역 안 압력은 **한 틱마다 고르게 맞춘다** (높은 칸에서 덜어 낮은 칸에 — 성분 · 열을 함께 옮겨 보존).
- **틈**: 구역 사이를 잇는 좁은 곳 (반쯤 열린 문 · 휜 문틀 · 벽의 금 · 구멍 · 환기구). 오리피스 식(막힘 흐름 포함)으로 흐른다.
  두 구역 사이의 흐름은 '두 통이 고르게 되는 정확한 지수식'으로 풀어 틱이 길어도 넘치지 않는다. 우주(진공)로 빠지는 것도 같은 식(정확한 지수 감소).
  틈으로 나가는 기체는 **틈 곁 칸의 것**부터 나간다 (구멍 곁 연기가 먼저 빨려 나간다).
- **확산**: 같은 구역 칸끼리 성분 · 열이 섞인다 (공기 흐름에 의한 섞임 · 분 단위). 그래서 연기는 불 곁에서 짙고, 숨 쉬는 사람 곁의 CO₂가 먼저 오른다.
- **바람**: 구역에서 틈으로 빠져나가는 흐름을 칸마다 계산한다 (틈까지의 거리 고리마다 지나가는 양 ÷ 고리 칸 수). 바람은 연기를 실어 나르고, 물건 · 사람을 민다.
- **경계**: 바깥은 진공(우주) 또는 행성 대기(성분 · 압력 · 온도 · 바람).

**열** — 기체 칸 · 바닥/벽(고체 칸)마다 온도. 기체 ↔ 바닥 · 벽 대류, 고체 ↔ 고체 전도(재질별), 외판 → 우주 복사, 햇빛 쪽 외판 가열, 장치 · 몸 · 불의 열.

**액체** — 칸 바닥에 고인 액체(물 · 냉매 · 연료)의 양 · 온도. 바닥을 따라 퍼지고, 증발(포화 수증기압) · 응결(차가운 벽에 이슬), 하수구로 빠진다.

**소리** — 소리는 '일'이 일어날 때 그 칸에서 퍼진다: 기체를 따라 칸마다 줄고, 벽 · 닫힌 문에서 크게 줄고, **진공에서는 전해지지 않는다**.
들은 사람만 안다 (⑧ 마음의 감각). 효과음도 여기서 나온 소리를 그대로 쓴다.

**빛** — 조명 · 불 · 창 · 화면이 칸마다 밝기를 만든다. 정전이면 어둡고, 연기는 빛을 가린다. 어두우면 사람이 덜 본다.

**냄새** — 기체의 미량 성분(음식 향 · 그을음 · 오존 · 썩는 냄새 · 암모니아)이 기체와 함께 퍼진다.

**방사선량** — 바깥 방사선(⑤)이 외판 · 벽 재질을 지나며 줄어 칸마다 선량이 된다. 방사선 대피실이 '저절로' 의미를 가진다.

**법칙 시험**: 닫힌 배에서 성분마다 몰 수 · 총 에너지 보존 · 음수 없음 · 좌우 대칭 방에서 대칭 · 구멍 난 구역은 0으로 ·
1코어 = 여러 코어 · 열 평형 · 소리는 진공을 못 건넌다.

**성능 목표**: 100명 배(약 2만 칸 · 성분 12)에서 장 전체 한 틱 평균 1ms 아래 (여러 코어).

### ④ 구조 · 물체 (`Structure`)
- 벽 · 외판 · 골조 칸마다: 재질 · 두께 · 온전함 · 피로 · 부식 · 온도.
- **하중**: 벽 양쪽 압력 차 × 넓이. 피로가 쌓일수록 견디는 힘이 준다. 넘으면 금이 가고(작은 틈) · 더 넘으면 터진다(큰 구멍).
- **충격**: ⑤에서 온 물체(질량 · 속도 · 각도)의 에너지가 외판을 뚫고(재질별 관통 에너지) 남은 에너지가 안쪽 칸으로 (파편 · 열 · 압력).
- **열 약화**: 뜨거운 벽은 약해진다 (불 곁 벽이 압력 차를 못 견딘다).
- **부식**: ② 반응(철 + 산소 + 습기) — 습한 방의 벽이 천천히 약해진다.
- **물건 · 사람의 밀림**: 바람 · 충격 · 가속도가 질량에 힘을 준다. 고정 안 된 물건이 날아가 다른 것에 부딪힌다.
- **법칙 시험**: 압력 차가 없으면 피로가 쌓이지 않는다 · 같은 충격이면 같은 구멍 · 결정론.

### ⑤ 바깥 세계 (`Outside`)
- **물체**: 별 · 행성 · 위성 · 파편 구름(입자 수 · 크기 분포 · 속도) · 운석 · 다른 배 — 배를 중심으로 한 평면 좌표에서 궤도 · 직선 운동.
- **충돌**: 물체(또는 구름의 입자)가 배의 외곽(외판 칸들)과 만나면 맞은 칸 · 각도 · 에너지를 ④로.
- **별**: 종류별 활동 주기 · 폭발(플레어) 확률 과정 → 바깥 방사선 · 햇빛 세기.
- **행성**: 중력 · 대기(성분 · 압력 · 온도) · 날씨(바람 · 모래 폭풍 · 온도 일교차) · 땅(광물). 착륙하면 격자의 바깥 경계가 된다.
- **이야기꾼이 할 수 있는 것**: 파편 구름 하나를 항로에 놓기 · 별 폭발 앞당기기 · 손님 배 보내기. 맞는 자리 · 결과는 엔진이 정한다.

### ⑥ 망 · 장치 (`Network`)
- **전기 회로**: 마디(배전반 · 분기) · 전선(저항 · 정격 전류) · 원천(원자로 · 배터리 · 태양판 · 보조 발전기) · 부하(장치).
  마디 전압을 반복법으로 푼다. 정격을 넘으면 전선이 뜨거워지고(그 칸에 열 → ③), 차단기가 떨어진다. 젖은 칸의 전선은 합선(물 + 전기).
- **배관**: 물 · 냉매 · 덕트 공기. 마디 압력 · 관 유량. 이음매가 낡으면 새고, 새는 것은 그 칸으로 (③ 액체 · 기체).
- **데이터**: 센서 → 주컴퓨터 → 문 · 밸브 구동기. 끊기면 주컴퓨터가 그쪽을 모른다 (⑩의 믿음이 틀린다).
- **장치**: 공정(② 반응식) · 포트(전기 · 관 · 칸의 기체) · 부품(마모 · 열 · 진동 · 부식이 쌓이는 상태). 고장은 **확률이 아니라 상태**에서 나온다.

### ⑦ 생명 (`Life`)
- **몸**: 숨(그 칸의 O₂를 빨고 CO₂ · 수증기 · 열을 낸다) · 체온(칸 온도와 주고받음) · 물 · 영양 · 피로 · 상처 · 병 · 약.
  **상처는 받은 에너지의 종류**에서 나온다: 열(화상) · 압력(감압 · 폭발) · 충격(뼈 · 멍) · 독(그 칸의 CO · 암모니아 …) · 방사선.
- **작물**: 빛 · 물 · CO₂ · 온도 → 자람(② 광합성). 병 · 해충.
- **미생물 · 곰팡이**: 습하고 따뜻한 칸에서 자란다 → 냄새 · 병원체 · 부식 · 음식 상함.
- **동물**: 반려동물 · 해충.

### ⑧ 마음 (`Mind`) — 사람 · 로봇 · 드론
```
감각 → 믿음 → 본능 → 욕구 · 감정 → 목표(점수로 고름) → 계획(단계로 쪼갬) → 동작(요청)
         ↑ 기억 · 성격 · 가치관 · 관계 · 솜씨
```
- **감각**: 눈(빛 · 시야 · 연기) · 귀(③ 소리) · 코(③ 냄새) · 몸(추위 · 숨 막힘 · 아픔) · 화면 · 방송 · 말.
- **믿음**: '안다고 생각하는 것' (어느 방에 불 · 누가 다침 · 산소가 모자람). 틀릴 수 있고, 오래되면 흐려지고, 말로 퍼진다(⑨). 오해가 이야기를 만든다.
- **본능**: 숨 막힘 · 불 · 진공 · 큰 소리 → 계획을 끊고 곧장 몸을 지킨다.
- **욕구 · 감정**: 배고픔 · 졸림 · 외로움 · 두려움 · 분노 · 슬픔 · 기쁨 · 기분.
- **목표**: 욕구 · 감정 · 믿음 · 성격 · 맡은 일로 점수를 매겨 고른다. 위험 회피는 점수 경쟁이 아니라 본능의 몫이다.
- **계획**: 목표를 단계로 쪼갠다 (계층 계획 — "불 끄기" = 소화기 찾기 → 가지러 가기 → 불 곁으로 → 뿌리기). 단계가 막히면 다른 방법.
- **이동 · 길찾기**: 100명 규모 · 혼잡 · 문 · 무중력 · 바람에 밀림 · 기어서 · 업고.
- **로봇 · 드론**: 같은 층 구조. 감정 대신 상태(전지 · 고장), 목표는 주컴퓨터의 배정에서.

**세부 (구현 기준)**
- **한 틱에**: 감각(매 틱 · 자기 방 칸만 훑는다) → 본능 검사(매 틱) → 고르기(2틱마다 · 사람마다 엇갈려) → 계획 한 걸음 → 걷기.
- **눈**: 같은 방(문 칸이면 옆 방) 칸 중 보이는 거리(③ 빛의 그을음 시야 · 어두우면 2m) 안. 불 · 연기 · 고인 물 · 벽 구멍(방 둘레 벽) · 쓰러진/죽은 몸 · 불꽃(합선) · 멈춘 장치.
  **안 보이면 지운다**: 불이 있다고 믿던 칸을 보고 있는데 불이 없으면 그 믿음을 지운다 ("꺼졌구나").
- **귀**: ③ 소리의 그 칸 들린 것 — 쾅(충돌) · 끼익(버티는 문 · 벽) · 쉬익(새는 곳) · 우르릉(불) · 비명 · 말. 소리 난 칸이 곧 믿음의 자리 (크기가 작을수록 덜 확신).
  **쉬익은 ③이 낸다**: 기압 차 5kPa 넘는 틈마다 5틱에 한 번, 높은 쪽 칸에서 (흐름이 클수록 크게).
- **코**: 그을음(타는 냄새 — 어딘지는 모름) · 암모니아 · 오존 · 음식 냄새(입맛). **일산화탄소는 냄새가 없다** — 두통 · 어지럼으로만 안다 (원인을 모른 채 "공기가 이상하다").
- **몸**: 숨참(산소 포화도) · 추위/더위(칸 온도) · 귀 먹먹(한 틱에 기압 3kPa 넘게 바뀜) · 바람(새는 쪽으로 분다 — 방향으로 새는 곳을 짐작).
- **믿음 하나**: 종류 · 칸 · 대상(사람 · 장치 · 문) · 확신 0~1 · 본 때 · 출처(봄 · 들음 · 냄새 · 몸 · 말 · 화면) · 원인. 사람마다 많아야 24개. 같은 종류가 가까우면(3칸) 합친다. 종류마다 반감기로 흐려진다.
- **말**: 급한 믿음을 처음 가지면 외친다 (③ 소리 '말' 75dB). 그 소리를 들은 사람은 같은 믿음을 '말' 출처로 (확신 × 0.8). 진공 · 닫힌 문 너머는 덜 들리거나 못 듣는다.
- **본능** (사람만 · 점수 경쟁 없음): 기압 40kPa 아래 · 산소 분압 14kPa 아래 · 산소 포화도 0.8 아래 · 옆 칸 불 · 칸 온도 330K 위 · 시야 3m 아래 →
  '도망'으로 바뀐다. 갈 곳 = 실제 공기가 좋은 가장 가까운 칸 (몸이 느끼는 대로 — 400칸 안 넓이 우선 찾기). 공기 때문에 도망치면 지나온 문을 닫는다.
  **공황**: 두려움 0.8 넘고 침착함 0.3 아래면 몇 분 동안 일을 놓고 숨거나 헤맨다.
- **욕구** (0~1, 1이 급함): 배고픔 6시간 · 목마름(몸의 물이 2% 줄면 1) · 졸림 16시간 · 어울림 · 놀이. **감정**: 두려움 · 슬픔 · 분노 · 기쁨 · 쌓인 긴장.
- **목표와 점수** (사람): 잠 · 먹기 · 마시기 · 일(근무 시간) · 쉬기 · 어울리기 · 불 끄기 · 구하기 · 구멍 막기 · 고치기 · 살피러 가기(쾅 · 끼익 · 쉬익 · 냄새) · 우주복 입기.
  점수 = 욕구나 믿음의 확신 × 성격 · 솜씨 × 거리 감점(1/(1+거리/40)). 지금 목표에 +1 (자꾸 바꾸지 않게).
- **일감 표시 (로봇이 먼저)**: 불 · 구멍 · 쓰러진 사람 · 고장마다 맡은 이를 적는다. 필요한 수가 차면 다른 이의 점수는 0.2배. **로봇이 맡은 일은 사람이 내려놓는다** — 사람은 로봇이 없거나 모자랄 때 나선다.
- **계획**: 목표마다 방법(단계 목록): 가기 · 집기(소화기 · 수리 꾸러미 · 봉합 꾸러미 · 우주복) · 쓰기(몇 분) · 뿌리기 · 막기 · 고치기 · 업기 · 내려놓기 · 문 닫기.
  막히면(문이 압력에 안 열림 · 물건 없음) 그 믿음을 적고 다시 계획한다.
- **물건**: 설비마다 처음 들어 있는 것 (표 `people.json` — 우주복 보관함: 우주복 · 소화기 / 작업대: 수리 · 봉합 꾸러미 / 선반: 소화기 · 봉합 꾸러미 / 산소 마스크함: 마스크).
  소화기는 물안개 9L — 뿌리면 불 칸 바닥에 물이 쌓이고 ② 화학이 그 물로 식힌다 (전기 설비 곁이면 ⑥ 합선이 날 수 있다 — 엔진이 알아서).
- **먹고 마시기는 물질로**: 먹으면 냉장고 · 배식기 칸의 양분(포도당)이 몸으로 · 마시면 ⑥ 물탱크의 물이 몸으로 (장부가 맞는다).
- **걷기**: 4방향 A* (가구 칸 +3 · 닫힌 문 +3 · 끼었거나 압력에 안 열린다고 믿는 문은 5분 동안 막힘 · 불 · 진공이라 믿는 곳 둘레는 비싸게).
  빠르기: 걷기 1.3 · 뛰기 3 · 연기 속 기기 0.6 · 업고 0.6 · 로봇 1 · 드론 2 (m/s, 칸 1m). 닫힌 문은 열기를 요청하고 열릴 때까지 기다린다. 지나간 문은 다시 닫는다 (배의 규칙).
- **로봇**: 전지(시간당 8% · 독에서 충전 — 망의 충전독이 돌아야) · 열에 상함(겉면 600K) · 진공 · 연기 무관. 목표는 일감(불 · 구조 · 구멍 · 고장 · 살피기)과 충전 · 대기. 감정 없음.
- **원인과 사실**: 사람이 한 일은 원인 마디가 된다 ("민수가 문을 닫았다"). 사실: 알아챘다 · 외쳤다 · 공황 · 불을 껐다 · 구했다 · 막았다 · 고쳤다.
- **시험**: 평시 하루(굶거나 목마른 사람 0 · 잠 6~9시간) · 불(로봇이 먼저 끈다 · 사람은 피한다) · 구멍(그 방 사람이 뛰어 문을 닫고 산다) · 일산화탄소(냄새로 못 알아챈다) · 구조(쓰러진 사람을 업어 낸다) · 틀린 믿음(꺼진 불을 아직 믿는다 → 가서 보고 지운다) · 압력에 안 열리는 문을 돌아간다 · 찍기/되살리기 · 결정론 · 100명 1틱 1ms 아래.

### ⑨ 사회 (`Society`)
관계(친밀 · 신뢰 · 원한) · 소문(믿음이 말로 퍼지며 바뀜) · 파벌 · 회의 · 투표 · 문화(관습) · 세대. 모두 '믿음과 관계' 하나의 규칙 위에.

**세부 (구현 기준 · 첫판)** — 엔진이다 (마음 다음에 돈다 · 찍기에 들어간다).
- **정** [나 × 너] −1 ~ 1: 함께 쉰 시간(같은 방 4칸 안 · 둘 다 쉬거나 어울리거나 밥 · 시간당 약 0.05 × 성격 맞음) · 구해 줌(업혀 나온 이 +0.45 · 구한 이 +0.2 · 곁에서 본 이 +0.1).
  0.5를 넘으면 '가까워졌다' · 구해지면 '목숨을 빚졌다' (사실 Relationship).
- **슬픔**: 죽음 → 남은 사람마다 0.15 + 정 (하루 반감) · 친구면 '잃었다'(Grieved) — 일 점수 × (1 − 0.7 × 슬픔) · 사람을 찾아 어울린다.
- **주컴퓨터에 대한 믿음** (처음 0.8): 주컴퓨터가 사람이 있는 채 닫은 방에서 30분 안에 누가 죽으면 모두 −0.25 (죽은 이와 정이 깊을수록 더) — '믿음이 깨졌다'(TrustLost).
  화면 · 경보로 받은 믿음은 × (0.3 + 0.7 × 믿음) — 덜 믿으면 다음 경보에 덜 움직인다.
- **마음에 닿는 곳**: 친구는 더 무릅쓰고 구한다 (구하기 점수 + 2 × 정 · 두려움도 정만큼 덜) · 어울릴 때 친구가 있는 방으로.
- **다음**: 소문(사람에 대한 믿음이 말로 퍼짐) · 원망(갇히게 한 사람) · 회의 · 투표 · 파벌 · 세대.

### ⑩ 주컴퓨터 (`ShipMind`)
- 센서(⑥ 데이터)로만 안다 → 믿음 → 할 수 있는 안 몇 가지 → **세계를 복제해 안마다 몇 분 앞을 실제로 돌려 본다**
  (자기 믿음으로 고친 복제 — 모르는 것은 모르는 채로) → 사람 · 배 · 시간 점수로 고른다 → 방송으로 설명 → 결과를 보고 배운다.
- 돌려 보기는 다른 코어에서, 틱 예산 안에서 (한 판단에 많아야 몇십 ms).

### ⑪ 일과 물자 (`Work`)
일감판(누가 무엇을 맡나) · 생산 사슬 그래프(재배 → 수확 → 조리 → 식사 / 원료 → 정제 → 부품 → 설비) · 막힌 마디 찾기 · 창고.

**세부 (구현 기준 · 첫판)** — 엔진이다 (요청 단계 · 1분마다 · 일감판은 5분마다).
- **저절로 만드는 설비**(표 `makers`): 정제기 2시간에 원료 하나(많아야 8) · 수집기 6시간에 하나 — 모자라고 전력에 여유(80% 안)가 있으면 켜고 다 차면 끈다.
  공장 설비 열의 80%는 냉각수 재킷으로 냉각 고리에 (모자라면 그 방으로).
- **만들기**(표 `recipes`): 봉합 꾸러미(원료 1 · 20분 · 4개 둔다) · 수리 꾸러미(원료 2 · 40분 · 3개) · 소화기(원료 2 · 30분 · 3개) — 배 전체 수가 모자라면 작업대 일감.
- **예방 정비**: 부품을 표준 수명의 80% 썼으면 미리 간다 (수리 꾸러미 하나) — 숨은 한계는 모른다: 어떤 고장은 막고, 어떤 것은 그래도 터진다.
- **청소**: 방마다 곰팡이가 0.3 넘는 가장 짙은 곳.
- **맡기기**: 놀고 있는 로봇이 먼저(가까운 순) — 없으면 일하는 시간인 사람 중 솜씨가 맞는 이. 비상 일(불 · 구조 · 막기 · 받치기)이 오면 일상 일은 놓는다 ·
  사람의 일상 일은 끼니 · 잠보다 앞서지 않는다 (맡김 보너스 +1).
- **다음**: 재배 → 수확 → 조리 사슬 · 창고와 나르기 · 막힌 마디 찾기.

### ⑫ 이야기꾼 (`Storyteller`)
긴장 곡선을 읽고, 원인만 심는다 (낡은 부품 · 파편 구름 · 별 폭발 · 손님 배 · 씨앗에 섞인 균). 가혹함 단계(옛 8단계 · 성격 6)를 그대로 고를 수 있다.

**세부 (구현 기준)** — 엔진이다 (세계를 바꾸므로 찍기에 들어간다). 30분(750틱)마다 생각한다.
- **지금 긴장**: 사실 흐름을 무게로 더하고 반감기 2시간으로 줄인다 — 죽음 10 · 쓰러짐 4 · 다침 1 · 벽이 터짐 3 · 불 2 · 경보 1 · 공황 2 · 문이 날아감 2 · 고장 1.
- **목표 긴장**: 성격마다 리듬 — 고른(하루 두 번 오르내림) · 잔잔한(낮게) · 몰아치는(높게 · 쉼 짧게) · 느린 불씨(낮게 · 대신 숨은 원인을 많이) · 우주의 변덕(바깥 원인만) · 사람의 이야기(작은 사고 · 사회 원인 — ⑨ 뒤).
  가혹함 1~8이 목표의 높이와 원인의 크기를 곱한다 (기본 4 '아슬아슬').
- **심기**: 지금이 목표보다 낮고 쉼(성격마다 2~8시간)이 지났으면 원인 하나 — 종류는 성격의 무게 × 같은 종류를 연달아 피함.
  파편 구름 · 운석(20~40분 앞에서 '다가온다') · 별 폭발 예고(조짐 먼저) · 부품 노화(⑥ 숨은 한계 가까이) · 외판 피로 · 부식 · 곰팡이 씨앗(습한 방) · 눌어붙은 차단기(⑥ — 다음 합선에 아크가 계속된다).
  심은 것은 원인 마디(이야기꾼)와 사실(StorySeed)로 남는다 — 결과는 엔진이 알아서 만든다 (안 만들 수도 있다).
- **시험**: 같은 시드는 같은 원인을 같은 때에 · 조용하면 심고 시끄러우면 쉰다 · 가혹함이 높을수록 크다 · 심은 원인이 실제 사건으로 이어진다(원인 사슬의 뿌리가 이야기꾼).

### ⑬ 연출 — 재미의 핵심 (`Director`)
- **관심 점수**: 사실 흐름(①)과 장(③) · 마음(⑧)을 읽어 칸 · 사람마다 '지금 볼 만한 정도'를 매긴다.
  위험(목숨이 걸림 · 간발의 차) · 사람 이야기(관계 변화 · 고백 · 다툼 · 희생 · 숨긴 실수) · 원인 사슬(작은 일이 번짐) · 처음과 드문 일.
- **조짐 보기**: 세계를 복제해 몇십 초 앞을 살짝 돌려 본다 → '곧 무슨 일이 난다'를 미리 알고 그쪽으로 카메라를 옮기며 시간을 늦춘다.
- **카메라**: 한 장면을 고르면 한동안 머문다 (마구 옮기지 않는다). 확대는 장면 크기에 맞춘다. 두 곳이면 나눠 보기.
- **시간**: 조용하면 빨리 · 조짐에 느리게 · 결정적 순간 느린 화면 · 끝나면 '조짐부터 다시보기'.
- **다시보기**: 몇 분마다 세계를 찍어 고리에 둔다 → 하이라이트의 원인 사슬 시작 직전 찍은 것부터 다시 돌려 보여 준다 (결정론이라 같은 일이 그대로 일어난다).
- **하루 모음 · 사진첩 · 결산 카드**: 그날의 장면들.
- **화면 겹침(설정)**: 기본은 눈에 보이는 것만. 기체 · 열 · 연기 칸 · 머릿속 · 원인 사슬 선 · 주컴퓨터의 상상(돌려 본 미래를 흐리게).
- **함장**: 손대면 잠깐 양보 · 몇 초 뒤 다시 맡는다.

**세부 (구현 기준)** — 엔진이 아니다: 세계 밖에서 매 틱 `Observe(sim)`로 읽기만 한다 (세계를 바꾸지 않으니 결정론 · 찍기와 무관).
- **관심**: 사실마다 무게(죽음 100 · 쓰러짐 40 · 구함 35 · 공황 30 · 벽이 터짐 30 · 문이 날아감 25 · 불 20 · 봉쇄(사람 안) 30 · 경보 10 · 조짐 15 …) ×
  원인 사슬 깊이(1 + 0.15 × 깊이) × 처음 보는 종류 ×2 — 칸에 쌓고 반감기 40초로 줄인다. 위험한 칸의 사람(산소 포화 · 쓰러짐 · 진공 · 불 곁)은 매 틱 더한다.
- **카메라**: 관심이 가장 큰 무리(반경 8칸)를 고른다 — 지금 장면보다 1.5배 넘어야 옮긴다 · 한 장면에 적어도 8초(화면 시간). 확대는 무리의 넓이에 맞춘다.
- **시간 (화면 1초에 몇 틱)**: 조용(관심 낮음) 60 · 조짐(다가온다 · 경보 · 끼익 · 심은 원인) 8 · 위험 2 · 결정적 순간(쓰러짐 · 터짐 · 죽음) 0.5를 3초.
- **하이라이트**: 관심이 문턱을 넘은 장면 → 제목(원인 사슬 글) · 그때 · 자리 · 시작(사슬의 뿌리 시각 — 첫 조짐).
- **다시보기 고리**: 2분마다 찍기를 1시간치(30개) 둔다 → 하이라이트의 시작 직전 찍기부터 되살려 같은 일을 다시 본다.
- **재미 측정기 (`Lab --fun`)**: 배 여러 척 × 며칠 — 시간당 하이라이트 · 종류의 다양함 · 원인 사슬 깊이 · 간발의 차(위험했다 산 사람) · 죽음 · 조용한 시간 비율 · 처음 보는 일 → 한 점수.

## 5. 사건은 이렇게 저절로 생긴다 — 원인 사슬 예

1. **파편** — 이야기꾼이 파편 구름을 항로에 놓는다 → ⑤ 입자 하나가 화물칸 외판에 → ④ 관통 · 구멍 → ③ 구역이 빠르게 빠지고 바람이 분다
   → 고정 안 된 상자가 날아가 문틀에 끼어 문이 안 닫힌다 → 옆 통로까지 빠진다 → ⑧ 그곳 사람의 본능(숨 막힘) → 업고 나오는 사람 → ⑬ 하이라이트.
2. **냉매** — ⑥ 오래된 냉각관 이음매 마모 → 새는 암모니아 → ③ 냄새 · 독 → ⑧ 냄새를 맡은 사람만 알고 말로 퍼진다 → 아직 모르는 사람이 그 방으로.
3. **전선** — ⑥ 과부하로 전선이 뜨거움 → ③ 열 → ② 피복 고분자가 탄다(불) → 연기 · CO → 차단기가 떨어져 조명이 꺼짐 → 어둠 속 대피.
4. **곰팡이** — 습한 재배실 → ⑦ 곰팡이 → 포자 → 기침 · 병 → 의무관이 원인을 못 찾음(믿음) → 주컴퓨터가 습도와 병을 엮어 낸다.
5. **피로와 실수** — ⑧ 잠 못 잔 기관사가 밸브를 반대로 → ⑥ 압력 → ④ 관 터짐 → 실수를 숨김 → ⑨ 소문 · 의심.

## 6. 재미 측정기 (`Lab --fun`)
하루를 돌려 다음을 잰다: 사건 수(사실 중 큰 것) · 원인 사슬 길이(평균 · 최대) · 아슬아슬함(간발의 차 · 살아남음) · 사람 이야기(관계 변화) ·
처음 · 드문 일 · 지루한 시간(관심 점수 낮은 연속 시간) · 사망. 층을 바꿀 때마다 점수를 남겨 추세를 본다.

## 7. 과정 — 설계 · 구현 · 고치기

**층마다 같은 순서로 돌린다.**
1. **설계**: 이 문서에 그 엔진의 상태 · 법칙 · 읽는 것/요청 · 데이터 표 · 법칙 시험을 적는다.
2. **법칙 시험 먼저**: 보존 · 대칭 · 결정론 · 경계를 시험으로 쓴다 (`Lab --law`).
3. **구현**: 데이터 표 + 법칙 코드. 아래 층의 상태만 읽는다.
4. **관찰 장면**: 작은 장면을 돌려 그림(칸 지도)으로 본다 (`Lab --scene 이름` → 그림 파일).
5. **재미 측정**: 위층이 생긴 뒤부터 (`Lab --fun`).
6. **커밋 · 푸시**: 빌드 + 법칙 시험 + 규칙 시험이 초록일 때만. GitHub Actions `engine`이 같은 것을 돌린다.

**고치기**
- 법칙 시험이 빨강이면 엔진 버그다. 시험을 끄지 않는다.
- 관찰 장면이 이상하면(연기가 벽을 넘는 등) 먼저 법칙 시험으로 재현한 뒤 고친다.
- 재미 점수가 떨어지면 원인을 사슬 단위로 찾는다 (어느 엔진이 사건을 막았나).
- 데이터 표를 바꾼 것은 표 검사가 먼저 잡는다.

**함장 확인 지점**: 층 하나가 끝날 때마다 README 맨 위(진행률 · 그림)와 이 문서의 진행 기록을 고친다.
