# 남은 큰 묶음 — 사용자와 정한 설계 (2026-10-12 밤)

진행 순서: 주컴퓨터 개편 → 연출 → 행성 → 항해 목적 → 세대 → 지식.
검증: 기능마다 빌드 + 그 기능 시험 → 올림 · **전체 회귀는 맨 끝에 한 번**.
승인: 답한 범위 안이면 진행 · 새 배 모양은 도안만 만들어 두고 확인받는다.
아침 보고: README 맨 위 + 화면 사진.

## 연출
- 사고 결산 카드: 지휘 건이 닫히면 큰 카드(무엇이 · 누가 · 잃은 것 · 지킨 것 · 로봇 활약 · 주컴퓨터 판단) → 잠시 뒤 접힘 · 연대기에도.
- 조명: 하루 주기(밤 복도 어둡게 · 방마다 불빛) + 사고 조명(경보 붉은빛 · 비상등 · 불빛 일렁임 · 로봇 헤드램프).
- 오늘의 장면: 그날 장면 1~3개를 그 순간 화면으로 남겨 하루 끝에 보여 주고 앨범에.
- 창밖: 항로 구간마다 다른 풍경(성운 · 행성 · 소행성대 · 정거장 · 얼음 구름) + 그 빛이 창가 방에 · 창가에 모여 구경.

## 행성 (극한 환경)
- 머무름: 임무 기간 + 이륙 여부는 판단 (배가 상하거나 날씨가 나빠지면 일찍 떠나거나 버틴다).
- 하는 일: 자원 채굴 · 정제 / 기지 확장(배 밖 방벽 · 온실 · 창고 · 탑) / 탐사(원정대 · 드론) / 생존.
- 만드는 법: **요소 조합 절차 생성 + 이름 붙은 특별 행성** · 난이도에 따라 확률로.
  요소: 온도 · 대기 / 지표 · 중력 / 날씨 / 땅 · 하늘 현상 + 그 밖에 떠오르는 것(자기장 · 고리 · 위성 · 조석 고정 · 결정 지대 · 유독 먼지 · 정전기 …).
- 생물: **일단 없음** (환경만으로 극한).
- 날씨 피해: 실제로 망가뜨린다 (번개 → 회로 · 로봇 · 태풍 → 바깥 구조물 · 고온 → 과열 · 바다 → 부식) — 부위별 상처 · 복구와 이어진다.
- 고르기: 주컴퓨터가 후보 2~3개를 원거리 관측(불확실)해 위험 · 보상 · 배 상태로 고른다 + 가끔 불시착. 난이도가 높을수록 후보가 험하다.
- 보기: 배 둘레 지면을 타일로.

## 항해의 목적 · 세대 · 지식
- 배 종류마다 임무(화물 · 탐사 · 구조 · 이민 · 채굴) · 항로 갈림길 · 시간 압박 · 늦게 오는 통신 · 도착 장면.
- 끝: 항해의 책 + 다음 항해로 일부 사람 · 로봇 · 주컴퓨터 경험 · 배가 이어진다.
- 세대: 나이 듦 · 은퇴 · 출산 · 아이 성장 모두 + 긴 항해는 조용한 달을 빨리 넘긴다.
- 지식 전수(사수 · 부사수 · 일지 · 잃는 솜씨 · 주컴퓨터 보관) + 외부 세계 기억(고향 · 남긴 사람 · 늦은 편지 · 기념일 · 향수병) 둘 다.
