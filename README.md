# ShipSim — 우주선 생태 관찰 시뮬레이터

스스로 살아가고, 망가지고, 수리하고, 적응하는 우주선을 지켜보는 게임입니다.
승무원 여섯 명(바꿀 수 있다)이 먹고 자고 대화하고, 채소를 길러 요리하고, 설비를 정비하고, 고장 나면 고칩니다.
아무 일이 없으면 우주선은 스스로 굴러갑니다 (90일 검증, 소모품도 남는 채소로 만들어 씀).

**v3: 플레이어가 사고를 일으킬 수 있습니다.** 운석을 떨어뜨리면 외벽이 단계적으로 부서지고, 공기가 새고,
격벽이 잠기고, 누군가는 우주복을 챙겨 실링폼으로 구멍을 막고, 누군가는 전기가 끊긴 방의 환기 댐퍼를 손으로 닫습니다.
화재는 산소를 먹고 번지다가 소화기에 꺼지고, 냉각을 잃은 원자로는 긴급 정지했다가 보조 발전기를 거쳐 다시 켜집니다.
사고가 끝나도 그을음·봉합 자국·용접 이음매가 남습니다.

**v4: 모든 사고가 결국 정상으로 돌아오지는 않습니다.** 부품이 없으면 설비를 20%·60%로만 살려 두고,
실링폼이 떨어지면 새는 구획을 포기해 용접으로 막아 버리고(침실을 잃으면 휴게실 바닥에서 잡니다),
진공에 갇힌 사람은 쓰러져서 누군가 우주복을 입고 업어 와야 하고, 우주복이 진공 속에 있으면 대담한 사람만 숨을 참고 뛰어듭니다.
사고 뒤에는 결과를 완전 복구 / 부분 복구 / 장기 장애 / 실패로 나눠 봅니다. 승무원 사망은 옵션입니다(`--death`).

**v5: 완벽하게 못 고칠 때 버티는 법.** 퓨즈가 없으면 살아 있는 회로에서 케이블로 임시 배선을 끌어오고(정격을 넘기면 달아올라 불이 납니다),
예비 부품이 없으면 함교 콘솔과 엔진을 뜯어 냉각 펌프를 고치고, 배터리가 빠지면 덜 중요한 회로부터 사람이 내립니다.
배터리도 보조 발전기 연료도 없는 **암흑 우주선**에서는 채소로 바이오 연료를 만들거나, 제어봉을 손으로 빼서 원자로를 자연 순환 냉각으로
저출력 기동합니다(과열될 수 있습니다). 침실을 잃은 지 오래면 휴게실에 간이침대를 놓아 임시 침실로 바꿉니다.
부품이 바닥난 채로 60일을 돌리면 우주선은 설계와 다른 모습이 됩니다 — 뜯긴 콘솔, 임시 배선, 폐쇄 구역, 임시 침실.

**v6: 재료와 순환 (리뷰어의 수리·자원 방향).** 선체 밖 채집 팔이 금속성 먼지·규산·탄소·얼음·드문 희귀 소재를 모으고,
승무원이 정제기에서 금속판·구조재·케이블·전자재·퓨즈·실링폼을 뽑고, 작업대에서 모터·펌프·베어링·전력 제어기·센서를 만듭니다.
얼음은 녹여서 공기 탱크를 다시 채웁니다. 그래서 평화로운 몇 주 동안 천천히 쌓고, 큰 사고 한 번에 몇 주 치를 씁니다.
수리는 연속선입니다 — 정품 부품이 있으면 정상 수리, 없으면 만들고, 만들 수도 없으면 **Mk.1 임시품**(출력 65%·전력 130%·빨리 닳음)을 현장에서 짜 맞추고,
그것도 안 되면 20/60% 땜빵과 부품 뜯기. 부품이 생기면 정품으로 되돌립니다. 여러 번 용접한 외벽은 구조재로 패널을 통째로 갈면 새것에 가까워지고,
정비실을 잃으면 창고 한쪽이 임시 정비실이 됩니다. 함선 지표(전력·생명유지·수리력·거주성·구조·엔진, 처음 = 100)로 우주선이 어떻게 달라졌는지 봅니다.

**v7: 역사와 진화.** 우주선은 겪은 것을 기억합니다. **연대기(J)**에 운석·화재·쓰러짐·죽음·결정·개조·교훈이 쌓이고,
벽·방·설비·사람마다 이력이 붙습니다("이 벽은 두 번 뚫렸고, 한 번 실링폼으로 막았고, 세 번 용접했다", "냉각 펌프 #2 — 고장 세 번 · Mk.3 개량형").
승무원은 **감압을 겪은 방을 무서워해** 돌아서 가고 그 방의 일을 남에게 미루고 그 방에서 자면 악몽을 꿉니다.
쓰러지거나 크게 다치거나 동료를 잃으면 **긴장**(스트레스 기저치)이 몇 주 남고, 사고를 함께 여러 번 넘긴 사람끼리는 **전우**가 되며,
사고를 넘길 때마다 조금씩 **침착**해집니다(당황하면 소화기를 엉뚱한 데 뿌리고 급한 수리에서 손이 떨립니다).
구획 포기·절전·부품 뜯기·방 개조는 이제 **사람이 정합니다** — 급하면 지휘 순서대로 깨어 있는 사람이 혼자, 아니면 회의로. 반대한 사람은 서운함이 남습니다.
평화가 이어지고 재료가 남으면 **겪은 사고에 맞춰 우주선을 고쳐 짭니다**: 운석이 들어온 자리에 보강판, 원자로가 멈췄던 배는 배터리 증설,
회로가 자주 끊긴 배는 필수 회로 예비 배선, 불이 난 방엔 자동 소화 장치, 자주 고장 난 설비는 Mk.3 개량형, 오래 쓴 임시 침실은 제2 침실.
같은 시드에서 사고 순서만 바꿔도 한 달 뒤 우주선과 승무원이 다르고, 어떤 지표는 처음보다 높아집니다.
**저장(F5)·불러오기(F9)**는 시드와 관찰자가 일으킨 사고만 저장하고, 불러올 때 같은 역사를 다시 돌려 한 틱도 어긋나지 않는지 지문으로 확인합니다.

**v8: 외부 작업과 구조 분리.** 방마다 선체 본체와 이어진 **구조 연결부**가 있습니다. 거대 운석(M)은 외벽을 뚫는 데서 끝나지 않고
연결부를 상하게 하고, 남은 연결부가 하중을 나눠 지다 약한 것부터 **피로로 끊어지며**, 다 끊어지면 **방이 실제로 떨어져 나갑니다** —
격자에서 방이 빠지고, 맞닿은 벽이 찢겨 외벽이 되고, 열려 있던 문 자리로 공기가 쏟아지고, 뜯긴 전선에 차단기가 떨어지고, 안에 있던 사람은 밖으로 튕겨 나갑니다.
에어락의 **드론 다섯 대**(검사·수리 둘·견인·건설)가 외벽을 돌며 상한 연결부를 찾고(검사 전에는 모른다), 밖에서 잇고, 잃은 골조를 다시 세웁니다.
드론은 전기(충전)·정비(부품)·자재(승무원이 거치대에 보급)가 있어야 일하고, 드론이 없으면 승무원이 **우주복을 입고 선체 밖으로(EVA)** 나갑니다.
버티지 못할 방은 회의로 **사출**합니다: 대피 → 물품 회수 → 전력·배관·환기 차단 → 격벽 용접 → 연결 해제 → 사출 (준비가 끝나기 전에 뜯겨 나가기도 합니다).
떨어진 방은 **견인 드론이 끌어와 계류 → 임시 도킹 → 되살릴지 회의 → 연결부 보강 → 전력·배관·환기 재연결**로 되살리거나, 너무 망가졌으면 잔해로 두고 부품만 꺼내 씁니다.
배전반이나 하나뿐인 해치가 있던 방은 무서워도 되찾아야 합니다. 구조 보기(V)에서 연결부와 하중이 보입니다.

**v9: 배관과 냉각 루프.** 원자로의 열은 이제 **관을 따라** 빠집니다: 고온관 → 냉각실 분기점 → (1번 펌프 → 방열판) ∥ (2번 펌프 → 방열판) → 귀환관 → 원자로.
관은 벽과 바닥 밑을 지나고, 운석 파편이나 배관 파손(P)에 **새다가(뜨거운 증기)** 심하면 **끊어집니다**. 분기 하나를 잠그면 냉각이 절반이 되어 부하가 차단되고,
고온관·귀환관이 끊어지면 냉각이 통째로 멈춰 원자로가 섭니다 — 냉각이 갑자기 줄면 자동 제어봉이 따라가는 동안 **노심이 달아올라 과열 정지**하기도 합니다.
냉각수는 새면 줄고(줄면 펌프가 헛돌며 닳고), **정수 탱크의 물로 보충**합니다 (보충관이 끊기면 물통으로 나른다) → 물 ↔ 정수기(전기) ↔ 원자로(냉각수)의 고리.
새는 본관을 **잠가서 원자로를 세울지, 새는 채로 냉각수를 부어 가며 버틸지**는 회의로 정하고, 고칠 재료가 없으면 새는 채로 다시 열기도 합니다.
고치는 길은 새 관(금속판 2) → 실링폼 클램프(임시, 압력에 다시 터질 수 있다) → **우회 배관**(금속판·실링폼, 흐름 70%, 흔적으로 남는다) → 엔진을 뜯어 금속판을 꺼내기.
선체 밖 **방열판**은 드론이나 EVA로 고칩니다. 급수 본관이 끊기면 수경재배대에 물이 가지 않아 작물이 말라 죽습니다. 배관 보기(V)에서 흐름·밸브·새는 곳이 보입니다.

**v9.2: 주 컴퓨터와 자동화.** 함교의 **주 컴퓨터**가 우주선의 반사 신경입니다: 감압이면 격벽을 잠그고, 불·감압이면 환기 댐퍼를 닫고,
감지기 경보를 온 배에 돌리고, 전기가 모자라면 우선순위대로 부하를 끊고, 드론을 관제하고, 냉각이 줄면 제어봉을 빨리 내립니다.
컴퓨터는 **전기와 환기**가 있어야 돕니다 — 환기 댐퍼는 컴퓨터가 움직이고, 환기 팬은 생명유지실(전기)이 돌립니다.
함교 댐퍼 구동기가 걸리거나, 생명유지실이 정전이거나, 함교가 감압되면 함교가 달아올라(38℃ 넘으면) **과열 정지**하고, 32℃ 아래로 식어야 다시 켭니다.
컴퓨터가 멈추면 **사람이 손으로** 합니다: 격벽을 돌려 닫고(12분 남짓), 댐퍼를 열고 닫고(15분), 불은 누가 보기 전까지 모르고, 회로는 사람이 내리고,
드론은 누가 거치대 콘솔에 앉아 **한 대씩 손으로** 몹니다 (함교가 뜯겨 나가면 주 컴퓨터도 함께 떠내려가니, 함교를 끌어오는 것도 손으로).
주 컴퓨터를 아예 잃으면 다른 방에 **임시 제어 컴퓨터**(Mk.1)를 짭니다.
자동화 없이 오래 버틴 배는 **손 조작 훈련**(교훈: 손 조작이 40% 빨라진다)을 하고, 배전실에 **예비 제어기**(격벽·댐퍼·경보만 맡는다)를 다는 개조를 합니다.

**v9.3: 저출력 운영.** 원자로가 제어봉을 다쳐 60%로 굳는 식으로 **전기가 모자란 채로 오래 가면**, 사람들이 회의로 무엇을 끌지 정합니다:
남은 분기 하나로 식힐 수 있으면 냉각 펌프 하나, 공기가 넉넉하면 산소 발생기 하나, 빈 치료 침대·엔진·콘솔을 내리고 **재배대·조리에 전기를 돌립니다**
(전에는 배전반 우선순위대로 재배대가 먼저 꺼져 열흘 안에 굶어 쓰러졌습니다). 원자로가 넉넉해지면 되돌립니다.
선반이 바닥났는데 사람이 할 일이 금속판을 기다리면, 드론 거치대에 실어 둔 것을 도로 꺼내 씁니다.

**v9.4: 문 구동기와 조명.** 문은 열릴 때마다 조금씩 닳고, 운석 파편·옆 칸의 불에 **구동기**가 망가집니다. 망가진 문은 전기가 있어도 손으로 천천히 열리고
(부상자를 업고 가는 길이 늦어지고) 감압 때 **저절로 잠기지 않아** 누가 돌려 닫아야 합니다. 모터로 갈거나, 없으면 케이블·금속판으로 느린 임시 구동기를 엮습니다.
**조명**은 운석·불에 나갑니다. 캄캄한 방(정전 포함)에서는 일이 20% 느리고(헬멧 등이 있는 우주복이면 괜찮다), 길을 꺼리고, 오래 있으면 불안합니다. 케이블 하나로 고칩니다.

**v10: 마감.** **소리**(치명 경보 사이렌 · 경고음 · 운석 충돌 · 원자로 긴급 정지, 배경의 기계음 · 공기 새는 소리 · 불 소리 — 파일 없이 시작할 때 만든다),
**설정 창**(O: 소리 크기·효과음·배경음, 치명 경보 때 저절로 멈추기, 사건 알림, 시작 배속 — 다음에도 남는다),
**관찰 보조**(N 가장 최근 사건으로 · [ ] 지나온 사고를 하나씩 · **R 그 사고 3분 전으로 되감기** — 같은 시드와 관찰자 기록으로 다시 돌려 같은 역사가 다시 흐른다),
**배포 설정**(`game/export_presets.cfg`: Windows·Linux),
**그래픽 업그레이드**(재질을 칸당 64 → 128px로 다시 만들고 창고·정비실 줄무늬판, 함교 패널, 에어락 경고띠를 더함 · 벽 아래 그늘 · 가구 그림자 ·
방마다 빛깔이 다른 천장 조명(정전이면 붉은 비상등, 조명이 나가면 캄캄) · 배경 성운).

**v10.1: 통신실, 승무원 수, 굶주림의 교훈.** 함교 위쪽을 막아 **통신실**을 냈습니다. 운석은 이제 던진 순간 부딪히지 않고 **6분 동안 날아옵니다** —
그 사이 누가 먼저 보느냐는 그때 배의 상태가 정합니다: **장거리 센서**(통신실, 전기)가 잡고 **주 컴퓨터**가 궤적을 계산하면 5분 전에
"몇 분 뒤 어느 방"이 온 배에 울리고, 그 방 사람은 빠져나가고, 방이 비면 자동화가 그 방 격벽·댐퍼를 미리 닫고, 선체 밖 사람은 에어락으로 돌아옵니다.
컴퓨터가 꺼져 있으면 궤적 계산이 없어 사람이 **통신실 레이더 화면을 지켜야** 2.5분 전에라도 방향을 알고(일손 하나가 묶인다),
센서마저 멈추면 함교·통신실 창밖을 보던 사람이 부딪히기 직전에야 "충격 대비!"를 외치고, 아무도 없으면 경보 없이 맞습니다.
**승무원 수**를 바꿀 수 있습니다(설정 창 O → 새 항해, 1~16명, 헤드리스 `--crew=N`). 침대는 여섯 개라 그 위로는 침실 바닥의 간이침대에서 자고,
사흘쯤 지나면 회의로 제대로 된 침대로 고쳐 짭니다. 사람이 많으면 **먹을 것과 물이 먼저 모자랍니다** — 굶주린 시간이 쌓이면 수경재배실(차면 휴게실·식당)에
**두 칸짜리 재배대**를 짜 넣는데, 재배대는 물을 먹으므로 물이 빠듯해지면 기관장·정비사가 반대해 부결됩니다(열 명은 20일을 버티고, 열여섯 명은 물이 바닥나 죽기 시작합니다).
운석 교훈으로 깐 **예비 배선**을 전력 지표가 이제 셉니다 (전에는 지표에 안 잡혀 사고 종류 게이트가 미달이었습니다).

**v10.2: 방 크기 개조 — 칸막이.** 큰 방(30칸 넘게)이 운석에 **통째로 감압**됐던 배는, 평화가 오면 그 방 가운데에 **칸막이 벽과 격벽 문**을 세워
방 하나를 둘로 나누는 안을 회의에 올립니다 (금속판 4 + 구조재 2 + 케이블 2, 여섯 시간). 설계도가 바뀝니다 — 격자에 벽과 문이 생기고, "식당 안쪽 칸"이라는
새 방이 생기며, 가구·문·구조 연결부·배관 밸브·공기·댐퍼 자리·사람들의 공포(무서운 방은 두 칸 다 무섭다)가 두 칸으로 나뉩니다.
다음 운석에는 **절반만 잃습니다** (게이트: 감압된 칸 67 → 38, 공기 탱크 −49% → −33%). 대신 문이 하나 늘고 넓은 방이 좁아져서, 식당·휴게실에서 모이던
사교적인 사람들이 "넓은 방이 좁아진다"며 반대합니다 (시드 20260929: 식당은 두 번 부결, 침실은 뚫린 지 여드레 만에 통과). 칸막이 줄 위에 가구가 있거나,
구조 연결부가 한쪽 외벽에만 있으면(수경재배실) 나눌 수 없습니다.

**v10.3: 신뢰성.** 코드 검토에서 재현된 문제를 고쳤습니다. 되감기가 그 뒤에 일으킨 사고를 버려 "같은 역사"가 아니던 것(이제 뒤의 사고도 제때 다시 일어나고,
새 사고를 일으키면 거기서 갈라집니다), 칸막이를 세운 뒤 승무원이 예전 경로로 새 벽을 지나던 것(걸음마다 길이 막혔는지 보고 다시 찾습니다),
개조 뒤 작업 대상이 옛 방을 가리키던 것, 방이 떨어져 나갈 때 열린 문과 닫힌 문이 똑같이 계산되던 것, 다른 방의 재배대가 급수 본관이 끊겨도 물을 받던 것,
저장 지문이 혈중 산소·방 온도·불·작물·난수를 보지 않던 것, 망가진 저장 파일에 멈추던 것, 한 프레임의 여러 경보 중 마지막만 보던 것.
헤드리스 `--selftest`가 열한 항목을 하나씩 다시 재현해 봅니다. 뒤의 로드맵도 검토를 받아 새로 짰습니다 (자원 회복 → 대인원 생활 → 공간 개조 → 예방 → 분산 운영 → 항로·교신 → 승무원 성장).

- **배 다섯 척** (v10.4): 제비호 4인용 · 미리내호 6인용(손으로 그린 기본 배) · 한빛호 12인용 · 은하호 20인용 · 천마호 30인용.
  사람이 늘면 배가 커집니다 — 원자로(3×3 → 6×6), 냉각 펌프, 배터리, 산소 발생기, 정수기, 재배대, 조리대·냉장고, 배식기, 침대, 선반, 작업대, 공기 탱크·물탱크·창고 물자까지
  인원에 맞춰 늘립니다 (`tools/shipgen/gen_ships.py`가 같은 뼈대로 짠다). 설정 창의 새 항해에서 배를 고르거나(자동이면 인원에 맞는 배), `--ship=Hanbit`.
  조리대가 여럿이면 여럿이 동시에 요리하고, 긴 개조 중에도 굶주리면 손을 놓고 먹으러 갑니다 (30인용 배가 굶던 원인 둘).
- **설비 단계** (v10.5): 열세 종류 설비에 2~4단계 — 원자로는 **핵분열로 → 개량 핵분열로 → 소형 핵융합로 → 대형 핵융합로**, 산소 발생기는 전해조 → 사바티에 반응기 → 조류 광합성조,
  냉각 펌프·정수기·재배대·배터리·작업대·정제기·채집 장치·보조 발전기·주 컴퓨터·센서·엔진까지. **연구**가 쌓여(작업대와 솜씨 좋은 사람, 하루 몇 점) 문턱을 넘으면 설계가 풀리고,
  올리는 건 개조 회의가 정합니다 (재료, 높은 단계는 희귀 소재. 겪은 일 — 정전·굶주림·원자로 정지 — 이 무엇을 먼저 올릴지 정한다). 공짜가 아닙니다: 출력이 큰 만큼 전기를 더 먹거나 더 빨리 닳거나 더 자주 고장 납니다.
- **방 모듈** (v10.6): 수경재배실 LED 생장 모듈(생장 +25%), 냉각실 열교환 모듈(냉각 +20%), 배전실 축전 모듈(+60kWh), 생명유지실 CO₂ 세정 모듈(산소 +15%), 정비실 정밀 가공 모듈(연구 +2/일).
  빈 바닥에 달고(길을 막지 않는 자리), 전기를 먹고, 닳고, 고장 나면 보너스가 사라집니다. 방 상세에 달린 것·더 달 수 있는 것이 보입니다.
- **UI** (v10.7): **T 기술 화면**(연구·다음 설계까지·설비별 단계 칩·모듈), 13명 넘으면 **부서별 두 줄 승무원 목록**, 설비 상세의 단계·다음 단계·재료, 30인용 배도 한 화면에 들어오는 확대 범위,

**v10.10: 선내 로봇 · 자원 회복.** 드론이 선체 밖을 돌보듯 **로봇**이 선체 안의 반복되는 일을 맡습니다 — 운반 로봇(배식기 채우기·드론 자재 보급·물통 급수·비상 물자),
정비 로봇(정기 정비·조명 갈기, 한가하면 긴 수리를 하는 사람 옆에서 **거들어** 35% 빠르게), 재배 로봇(작물 돌보기·수확), 방재 로봇(순찰하며 불과 사고 전조를 찾고 소화 거품).
로봇은 방마다 벽에 붙은 **충전대**에서 전기를 받아야 움직이고, 닳으면 고장 납니다. 바퀴에 이물질·센서 오차·모터 과열 같은 **가벼운 고장은 충전대로 느리게 돌아가 스스로** 고치고,
상태가 **임계점(35%)** 아래이거나 자가 수리를 세 번 넘기거나 구동 모터·제어기·셀·그을림 같은 심한 고장이면 **사람이 부품을 들고 가서 고칩니다**.
방전돼 멈춘 로봇은 사람이 충전대까지 끌고 오고, 로봇이 멈추면 그 일은 다시 작업 목록으로 돌아가 사람이 합니다(로봇이 하던 긴 일에 사람이 합류하면 진척이 이어집니다).
**자원 장부**가 공기·실링폼·냉각수·금속판·물·식량·얼음의 하루 수입과 사고마다 쓴 양, 사고 전 수준으로 돌아오기까지 걸린 날을 적고,
비축 방침이 평시 → 사고 직후(목표 +30%) → 극한(살 길부터)으로 바뀝니다. 창고 밖에 **비상 물자함**(실링폼·구급 키트·소화기)을 나눠 두고,
사고가 끝나면 임시 배선을 걷어 케이블을 되찾고, 빈 간이침대를 접고, 뜯긴 설비를 재활용합니다. 급수 본관이 끊기면 물통으로 재배대에 물을 나릅니다.

**v10.11: 대인원 생활 — 조리사와 배급.** 큰 배에는 **조리사**가 탑니다 (재배 담당 후배를 한 사람 걸러: 12·20인용 하나, 30인용 둘).
조리사가 부엌을 맡고(사흘에 조리사 평균 56인분 ↔ 재배 담당 14인분) 재배 담당은 재배대에 붙습니다. 먹을 것이 **이틀치 아래**로 떨어지고 재배대가 먹는 만큼 대지 못하면
주방에 **배급표**를 붙이자는 안이 회의에 오릅니다 — 부엌을 맡은 사람은 찬성, 많이 먹는 사람과 다친 사람을 돌보는 의무관은 반대.
배급 중엔 한 끼씩 줄여 허기가 덜 빠지고(먹는 양 −28%), 대신 늘 조금 배고파 날카로워지고 손이 조금 느립니다. 나흘치 넘게 열두 시간을 버티면 뗍니다.
시험: 먹을 것이 하루치뿐이고 재배대 절반이 망가진 12인 배 — 배급하는 배는 나흘 동안 굶주림 83사람·시간, 배급 없는 배는 187. 배급한 시간은 굶주림의 절반으로 쳐서 재배대 증설의 교훈이 됩니다.
상단에 `먹을 것 N일치`(사흘치 아래) · `배급` 칸.

**v10.12: 공간 개조 — 칸막이 철거와 설비 옮기기.** 칸막이는 영원하지 않습니다. 가른 뒤로 한 번도 뚫리지 않고 열이틀 넘게 평화로웠던 방(특히 식당·휴게실·주방)은
사교적인 사람들이 **칸막이를 걷자**고 합니다 — 넓은 방이 그리운 사람은 찬성, 그 방에서 감압을 겪었거나 칸막이 덕을 본 기관사·정비사는 반대. 통과하면 벽과 격벽 문이 바닥이 되고,
떼어 냈던 칸의 가구·문·연결부·밸브·공기(부피대로 섞인다)·사람들의 기억이 원래 방으로 돌아가며, 벽 재료(금속판 3 + 구조재 1)를 되찾습니다. 다음 운석에는 다시 통째로 감압되고,
걷은 뒤에 또 뚫리면 다시 칸막이를 칩니다. **설비 옮기기**: 두 번 넘게 뚫렸거나 버린 적이 있는 외벽 방의 산소 발생기·배터리·작업대·치료 침대·정제기·우주복 보관함·선반을
외벽이 없는 안쪽 방의 빈 자리로 옮깁니다 (설비의 이력·마모·단계는 그대로 따라가고, 배관·덕트에 물린 펌프·원자로·엔진·정수기·재배대는 못 옮깁니다).
시험: 칸막이를 세웠다 걷으면 칸·가구·문·연결부가 원래대로 · 18일째 회의로 통과(찬성 3 · 반대 0 "넓은 방으로 돌아가자") · 세 번 뚫린 배전실의 배터리가 안쪽 생명유지실로.

**v11.0: 예방과 안전.** 닳아서 날 고장의 일부(기본 65%)는 몇 시간~하루 먼저 **전조**(배선 과열·진동·압력 변화·계기 이상)를 냅니다.
감지기(주 컴퓨터)·그 방 당직의 솜씨·방재 로봇과 사람의 **순찰**이 먼저 보면 케이블 하나·윤활유 하나로 손봐 막고, 아무도 못 보면 그대로 고장 납니다 (배선 과열은 불이 되기도).
안전 담당이 **우주복 점검**(오래 안 본 보관함의 우주복은 밸브가 새 산소가 빨리 준다)과 **비상 훈련**을 챙깁니다.

**v11.2: 엔진실의 존재 이유 — 회피 기동과 항로.** 엔진은 이제 **연소할 때만** 전기를 크게 먹고 **추진제**(정수 탱크의 물을 옮겨 채운다)를 태웁니다.
센서가 운석을 일찍 보면 **회피 기동**으로 비킵니다 — 자동 조종(주 컴퓨터 + 함교 조타 콘솔), 아니면 함교에 앉은 사람의 손 조종, 아니면 엔진실 사람의 현장 조종.
추력·조종 솜씨·남은 시간이 넉넉하면 완전히 비껴가고, 모자라면 스치기만(충격 절반) 합니다. 엔진이 멎은 배는 그대로 맞습니다.
**항로**: 원료가 모자라면 회의로 **잔해 지대**(채집 1.7배, 대신 작은 운석이 날아든다)로 옮겼다가 맞거나 채울 만큼 채우면 빠져나옵니다 — 엔진이 멎으면 빠져나올 수 없습니다.
그래서 물 ↔ 정수기(전기) ↔ 엔진(추진제) ↔ 채집(원료)의 고리가 하나 더 생겼습니다.

**v11.1: 분산 운영 — 핵심 방 하나를 잃어도.** 평화로울 때 겪은 일(방이 뚫림·자동화 꺼짐·임시 정비실을 짜야 했음)과 배 크기를 보고 **미리 나눠 둡니다**:
작업대가 한 방에만 있으면 창고 같은 안쪽 방에 **보조 작업대**, 함교가 뚫렸거나 자동화가 꺼졌던 배는 엔진실에 **예비 조타석**(함교를 잃어도 자동 조종·손 조종으로 회피 기동과 항로 변경),
산소 발생기가 모두 한 외벽 방에 있고 그 방이 뚫렸으면 하나를 안쪽 방으로. 미리 못 나눈 배를 위한 비상 수단으로, 돌아가는 산소 발생기를 모두 잃은 지 한 시간이면
전력 제어기·케이블·금속판으로 **임시 산소 발생기**(Mk.1)를 짭니다 (느리고 비싸게나마 버틴다).
게이트 `--gate=distributed`(한빛호 4쌍, 방을 떼어 내고 나흘): 정비실을 잃으면 작업대 없이 4시간 ↔ 0시간, 함교를 잃으면 비키거나 스친 운석 0.3 ↔ 3.5,
생명유지실을 잃으면 최저 산소 15.2 ↔ 16.3kPa (임시 산소 발생기가 없던 때는 몰아 둔 배의 열두 명이 모두 쓰러졌다).

**v11.2: 외부 교신 — 조난 신호와 탈출 캡슐.** 통신실의 또 하나의 존재 이유입니다. 공기 탱크 20% 아래 · 먹을 것 하루치 남짓 · 물 10% 아래 · 실링폼 없이 새는 방이면
회의로 통신실에서 **조난 신호**를 보냅니다 (엿새에 한 번). 하루~이틀 뒤 **보급 캡슐**이 에어락 바깥 해치에 붙고, 누가 가서 짐을 내려야 식사·실링폼·금속판·필터·구급 키트·케이블이 창고에 들어가고
공기 탱크·물탱크가 찹니다. 근처 **탈출 캡슐의 구조 요청**(사고 도구 "더 보기"의 구조 요청 · 무작위)을 받으면 하루 안에 회의로 건질지 정합니다 — 의무관은 "사람을 두고 갈 수 없다",
부엌을 맡은 사람은 먹을 것이 모자라면 "입이 는다", 기관사·항법사는 추진제가 모자라면 반대. 건지면 추진제를 써서 다가가고, 다친 생존자 1~3명이 에어락으로 올라와 새 승무원이 됩니다
(침대가 없으면 간이침대). 통신실을 잃은 배는 도움을 청할 수도 들을 수도 없습니다. 시험 `--commstest`: 공기 탱크 12% → 조난 신호(7:0) → 25시간 뒤 캡슐 → 12% → 55% ·
구조 요청(5:2 "잘 자리가 없다") → 두 명 합류·치료 · 저장·불러오기.

**v11.3: 승무원 성장과 회복 — 배우기, 재활, 후유증.** 어떤 솜씨를 가진 사람이 배에 하나뿐이면(의료·기관·전기·항법·정비·재배·조리 0.6 넘게), 평화로울 때 후배 하나가
그 사람 **곁에서 일을 따라 하며 배웁니다** (비번 시간에 · 깨어 있는 시간이 겹치는 사람을 골라 · 선배 솜씨의 90%까지 · 35%·50%를 넘으면 연대기에 "배워서 혼자서도 맡을 수 있다").
그래서 핵심 인력이 쓰러지거나 떠나도 그 일을 할 사람이 남습니다 — 20일 평화 뒤 의무관이 빠지고 셋이 다친 시험에서, 배운 배는 의무관 말고 가장 나은 의료가 59%(안 배운 배 32%),
치료 한 번에 부상 11.8%p(8.2), 첫 치료 1.2시간(2.2), 12시간 안에 나은 부상 171%p(111). 다친 사람은 하루 한 시간 의무실(없으면 휴게실)에서 **재활 운동**을 합니다 — 의무관이 같은 방에 있으면 더 빨리 낫습니다
(70% 부상이 사흘째 0~6% ↔ 재활 없이 11~14%). 절반 넘게 다치면 **후유증**이 남아(최대 체력·손이 조금 둔하다) 재활로 절반까지만 줄어듭니다. 승무원 상세에 후유증 · 배움 · 가르침 · 재활 횟수.

**v11.3 다듬기.** **미니맵**(G, 아래쪽 기록 옆 — 큰 배에서 어디서 무슨 일이 나는지 한눈에, 누르면 그곳으로). **단계마다 다른 설비 모양**: 딱지만이 아니라 모양이 바뀝니다 —
산소 발생기 II 사바티에 반응기(달아오른 반응관·코일) · III 조류 광합성조(초록 물에 오르는 거품), 정수기 II 증기 압축(도는 압축기와 김) · III 폐쇄 순환(파랗게 도는 흐름 고리),
재배대 II LED(보랏빛 광원 막대) · III 에어로포닉스(뿌리에 뿌리는 안개), 배터리 II 고체 전해질(충전량만큼 켜지는 칸) · III 초전도(서리 낀 고리), 작업대 II CNC(오가는 가공 머리) · III 적층 제조기(쌓이는 층),
냉각 펌프 II 압력계 · III 얼음빛 테, 정제기 플라스마 아크, 연료전지 셀, 분산 제어 노드 격자, 위상 배열 소자판, 이온 추진기의 푸른 빛. 전기가 없으면 빛이 죽습니다.
**전력을 보고 올리기**: 단계를 올리면 전기를 더 먹는 설비(재배대·정수기 등)는 원자로 정격의 92% 안에 들 때만 올립니다 (30인 배가 무턱대고 올리다 부하 차단·CO₂ 2.9%에 빠지던 것).
**조리사**: 근무 중이면 비번 동안 먹을 것까지 미리 해 두고(식사 목표 1인 4끼), 조리사가 있는 배에서 다른 사람은 식사가 한 끼 반치 아래일 때만 부엌에 섭니다 — 조리사 몫 77~88%.
**임시 산소 발생기**는 하나만: 전기가 없어 안 도는 발생기도 "있다"로 봅니다 (원자로가 멎은 사이 둘을 짓던 것).
**큰 배 연구 체감**: 하루 연구가 9점을 넘으면 넘는 몫은 45%만 (30인 배가 열흘이면 모든 설계를 풀던 것 — 열흘 연구 6인 80 · 12인 119 · 30인 173). 수치 조정 창의 `research.knee`·`research.beyond`.
**소리에 자리**: 운석 충돌·공기 새는 소리·불 소리가 그 자리에서 들리고(화면에서 멀면 작게, 왼쪽이면 왼쪽 귀로), 문이 열리고 닫히는 공압음, 가까이 볼 때(1배속) 승무원 발소리와 로봇 구동음.
**난수기**: `System.Random`(시드가 이웃하면 첫 값들이 서로 닮았다 — 16번의 회피 기동이 모두 같은 쪽으로 빗나갔다)을 xoshiro128\*\*(SplitMix64로 시드)로 바꿨습니다. 저장 12판 (11판 이하는 역사가 다르게 흐른다).

**함교 홀로그램 테이블** (v11.2, 화면): 함교 바닥의 투사 패드 위에 배의 축소 모형이 떠 있습니다 — 방마다 상태 색(평상 · 급함 · 치명 · 버림), 날아오는 운석과 들어올 외벽,
연소 중인 엔진 불꽃, 잔해 지대의 부유 입자, 태양 폭풍의 잡음 줄. 함교가 정전되면 꺼지고, 주 컴퓨터가 꺼지면 지지직거립니다.

**v11.2: 사고 종류 15가지 더 + 무작위 사고.** 사고 도구 줄의 **더 보기 ▾**에서 고릅니다. ●는 배 전체에 바로, ○는 대상을 고른 뒤 클릭:
**운석우**(30분 동안 5~8개) · **태양 폭풍**(몇 시간 동안 센서가 흐려지고 전자 장비·로봇이 튀고, 선체 밖은 방사선 — 선외 작업을 미룬다, 하늘에 오로라) ·
**전력 서지**(차단기·단락·임시 배선이 타고 배터리가 줄고 조명이 나간다) · **유독 가스**(방을 클릭: 설비의 냉매가 새서 방이 우주복 없이는 못 들어가는 곳이 된다 —
댐퍼가 닫히고, 누가 우주복을 입고 들어가 실링폼으로 막고, 막은 뒤 환기가 걷어 낸다) · **병충해**(재배대: 잎에 반점이 번지면 알아채고, 로봇이 아니라 사람이 약을 쳐야 하고, 두면 옆 재배대로 옮아 작물이 죽는다) ·
**식중독**(냉장고·배식기: 균이 든 식사가 나르는 손을 따라가고, 먹은 사람이 앓아눕고, 같은 묶음을 찾아 버린다) · **주 컴퓨터 오류** · **로봇 오작동**(비틀거리다 옆 사람을 칠 수 있다) ·
**선체 피로 균열**(외벽 두세 칸이 갈라져 새고, 용접해도 예전만 못하다) · **원자로 이상**(제어봉이 걸리고 노심 온도가 뛴다) · **문 고장** · **조명 나감** · **작업 사고**(승무원을 클릭) ·
**잔해 구름**(잔해 지대로 밀려나 엔진을 태워 빠져나와야 한다) · **물 오염**(탱크 물 일부를 버리고 정수기 필터가 막힌다).
**무작위 사고**(끔 · 드물게 6일 · 보통 3일 · 잦게 하루 반 · 혼돈 반나절 — 더 보기 메뉴나 설정 창 O): 켜면 관찰자가 던지지 않아도 배가 평균 그 간격으로 사고를 겪습니다
(고전 사고 — 운석·화재·고장·배관 — 와 새 사고를 섞어서). 따로 떼어 둔 난수로 뽑아 **되감기·불러오기에도 같은 때 같은 사고**가 나고, 꺼 두면 역사가 한 틱도 달라지지 않습니다.

  **공기 구역**을 정해 사람을 모으고 그 구역부터 채운다. 관제 화면(Y)에 모듈·방침·진행 중인 수순과 카운트다운.
- **v13.1 지휘**: **선장**(권위형·협의형·방임형, 신뢰가 무너지면 불신임 → 선거)과 **현장 지휘**(사람 · 컴퓨터 · 상황 따라). 위기면 **조**를 짠다 —
  소화조·봉합조·구조조·전력조·치료조와 대기조, 위험한 방은 **2인 1조**(짝이 문 밖에서 지키다 쓰러지면 끌어낸다), 지치면 **교대**. 도면에 별·조 배지.
- **v13.2 회의 개편**: 회의가 넷 — **긴급 판단**(선장 혼자) · **현장 협의**(위기 중 무전) · **정기 회의**(하루 한 번 회의실·식당에 실제로 모인다) · **사후 검토**(사람이 죽으면
  그 방침을 다시 올린다). 의견은 가치관·경험·상태·죄책감에서 나오고, **설득력 있는 사람의 발언이 표를 뒤집는다**. 정한 일로 사람이 죽으면 **죄책감과 비난**,
  같은 가치관끼리 **파벌**. 첫 출항 회의가 가치관대로 방침을 정해 **배마다 문화가 다르다**. 방침은 **26개**(구조·대피·원자로·소화 수단·사출·차단·소집·자동 실행·
  관제석·정보 공개·배급·물·비축·부품 뜯기·기항지 지출·의약품 추가). **E**로 방침·회의 화면(회의록 카드 · 파벌 · 신용 · 죄책감).
- **v13.3 판단·인지·감정**: 승무원은 모든 것을 알지 못한다 — 사고는 **직접 보거나 · 경보로 · 무전으로 · 소문으로** 알게 되고, 데이터선이 끊긴 방의 불은
  누가 지나가다 볼 때까지 아무도 모른다. **공황**(난이도가 높을수록 잦고, 가혹에서는 얼어붙는다) · **분노**(지시를 덜 따른다 → 명령 무시) · **영웅심**(우주복 없이
  뛰어든다). 지금 하는 일이 **생존 · 맡은 역할 · 일 · 생활** 중 어디인지 보이고, 컴퓨터는 소화 수순의 결과로 **신뢰와 별명**을 얻는다.
- **v13.4 사회**: 방침이 **46개**가 됐다(근무 교대 · 야간 당직 · 정비 · 개조 · 연구 방향 · 훈련 · 여가 · 사생활 · 장례 · 추모 · 갈등 해결 · 규칙 위반 · 수습 ·
  아이 교육 · 출산 · 은퇴 · 항로 · 구조 신호 · 난파선 · 교신). 배 전체 **사기**가 손 빠르기·다툼·공황·실수 숨기기를 바꾸고, 사고를 열두 번 넘긴 사람은 **베테랑**이
  된다. 덜 조인 실수를 **숨긴** 사람은 나중에 고장으로 드러나 조사에 걸리면 벌을 받는다. 판단 탭에 **일과표** 띠, 방침·회의 화면에 **사기 그래프**.
- **v14.0 승무원 개성**: 경력 **40** · 습관 **40** · 자격 **20** · 취미 **30** · 두려움 **20** · 말버릇 **30**. 습관은 숫자로 된 효과(스트레스·식욕·잠·실수·손 빠르기·
  공황·설득력·잠드는 시각·다툼)를 갖고, 취미가 있으면 쉴 때 그 방을 찾아가 더 풀리고 같은 취미끼리 가까워진다. 두려움이 건드려지면 그 일을 꺼리고 공황이 잦다.
  회의 발언에는 저마다의 말버릇이 묻어난다.
- **v14.1 질병 30**: 열병에 감기·장염·폐렴·감압병·방사선 병·저체온증·괴혈병·근육 위축·치통·상처 감염·불면증·우울증·외상 후 스트레스 등 29가지를 더했다.
  저마다 원인이 되는 조건이 있고, 증상(손·걸음·잠·공황·체력)이 있고, 낫는 길(침대·약·먹기·운동·곁에 있어 주기)이 다르다. 진단 전엔 "어딘가 아프다"일 뿐이다.
- **v14.3 개인 물건 · 취미**: 책·악기·체스판·스케치북·공구 가방·사진·담요에 주인과 이력이 있다. 취미는 물건을 꺼내 와서 하고, 경보가 나면 펼친 채 두었다가
  돌아와 이어 한다. 체스는 상대를 기다리고, 그림은 완성되어 휴게실에 걸리거나 선물되고, 밤의 기타 소리에 옆방 사람이 깬다. 젖은 책은 친구가 말려 주고,
  떠난 사람의 공구는 제자에게 간다. 승무원 카드의 **물건** 탭에서 어디에 있는지, 무슨 일을 겪었는지, 왜 그런 사이인지 본다.
- **v15.2 고장 70 · 물자 70**: 개스킷 누설 · 릴레이 붙음 · 임펠러 침식 · 펌웨어 멈춤 등 고장 40가지와 부품·소모품 44가지 — 새 부품은 필요할 때 정비실에서 만들고, 비누·세제·소독약·붕대·절연 테이프·커피는 씻기·빨래·관 씻기·응급 처치·임시 이음·일상에서 실제로 줄어든다.
- **v15.1 사고 70**: 차단기 연쇄 · 접지 불량 · 배관 동결 · 오수 역류 · 단열재 그을음 · 문 씰 손상 · 베어링 고착 · 용접부 피로 · 이온 폭풍 · 기름 화재 · 곰팡이 · 공황 발작 등 44가지를 더했다 — 모두 이미 있는 고장·불·망·공기·오염·병으로 엮여 승무원이 아는 대응으로 수습한다. 구급 키트가 바닥나면 응급 처치로 버틴다.
- **v15.0 일상 사건 70**: 사고가 아닌 날에도 배는 산다 — 태운 저녁, 코골이, 손으로 깎아 준 배 모형, 선배의 요령, 먼저 건넨 사과, 덕트로 온 주방 냄새, 설비의 별명, 창밖의 성운, 집에서 온 소식.
  열 갈래 일흔 가지가 저마다 습관·취미·두려움·경력·관계·물건·설비에 붙어 누가 왜 했고 무엇이 바뀌었는지 남긴다 (일기 · 관계 기억 · 배 기록).
- **v14.9 배의 문화**: 겪은 일이 관행이 된다 — 큰불을 겪은 배는 밥 먹기 전에 소화기 자리를 보고, 사람을 잃은 배는 추모일에 그 자리에 물건을 놓고, 물이 바닥났던 배는 넉넉해도 아껴 씻는다.
  신입은 처음엔 모르다가 설명을 듣거나 보고 따라 하고, 이유를 아는 사람이 다 떠나고 기록도 없으면 이유는 잊히고 행동만 남는다. 같은 설계의 배가 서로 다른 공동체가 된다.
- **v14.8 배관·배선 전달량**: 이어졌나가 아니라 얼마나 오나 — 방마다 전압·수압이 0~100%로, 보조 간선으로 돌면 가늘어 모자라고, 많은 방을 나르는 임시 이음은 달아오른다(이은 사람이 기억한다).
  수압이 떨어진 방의 더러운 물은 급수관으로 거꾸로 들고, 보조 간선이 주 간선과 같은 방을 지나면 한 번에 둘 다 끊긴다. 문 양쪽 기압이 다르면 균압 밸브로 맞추고 열며, 에어락은 점검 → 감압 → 가압 → 털기.
- **v14.7 오염 · 위생**: 정비하면 손에 기름이, 불을 끄면 옷에 그을음이, 선외 작업을 하면 우주복에 분진이 묻고, 그게 손과 옷에서 방으로, 방에서 다른 손으로 옮겨 다닌다.
  조리·치료 전에는 손을 씻고(급하면 건너뛰고 그게 남는다), 일이 끝나면 씻고 갈아입고, 빨래는 세탁실에서, 우주복은 들어오기 전에 턴다. 물이 모자라면 손만 대충 씻고 빨래를 미룬다.
  씻지 않은 손으로 만든 식사에는 균이 들고, 더러운 손으로 만진 상처는 곪는다.
- **v14.6 부품마다의 수명과 내력**: 같은 설비 안에서도 부품마다 나이가 따로 간다 — 베어링을 갈면 베어링만 새것이고 모터와 씰은 그대로다.
  부품마다 어디서 왔는지(기항지 묶음 · 떼어 온 중고 · 누가 손으로 만든 것)가 남고, 일찍 나간 부품의 묶음은 다른 설비와 선반의 것까지 의심받는다.
  같은 자리가 또 나가면 그 설비를 여러 번 만진 사람이 원인(옆 설비 열기 · 축 정렬 · 부품 불량)을 찾아 바로잡는다. 시험대 · 호이스트 · 정비 카트를 정비실에 달고,
  호이스트 없이 무거운 부품을 혼자 들다 허리를 삐끗하기도 하며, 빽빽한 방은 큰 수리가 느리다.
- **v14.5 움직임 · 몸짓**: 좁은 통로에서 마주치면 순서가 낮은 쪽이 벽에 붙어 비켜선다(환자를 업은 사람 → 급하거나 비상 대응 중인 사람 → 짐을 든 사람 순).
  통로에서 일하는 사람이 길을 막으면 잠깐 기다렸다가 크게 돌지 않는 길이 있으면 돌아가고(그 방이 기억한다), 없으면 양해를 구하고 비집고 지나간다.
  자는 사람이 있는 방은 발소리를 죽여 천천히 걷고, 급히 뛰어 지나가면 선잠이 깬다. 너머가 위험한 문 앞에서는 멈춰 계기를 보고, 위험한 일을 맡은 조는
  감시자를 기다린다. 비상이 나면 나르던 먹을 것·원료는 그 자리에 내려놓고 달려가고(공구·부품은 들고 간다) 조용해지면 챙긴다. 폭발 · 운석 · 파열 소리에 가까운 사람은 움찔하며 그쪽을 본다.
  다리를 다치면 절뚝이고, 지치거나 앓으면 몸을 숙인다.
- **v14.4 관계의 이유 · 대화**: 사이마다 까닭이 남는다(구해 줬다 · 경고를 무시했다 · 근무를 대신 서 줬다). 쓰러진 사람은 곁을 떠난 사람을 "나를 두고 갔다"고
  기억하지만, 그가 찾아와 우주복을 가지러 갔던 거라고 말하면 바뀐다. 힘들어 보이는 동료에게 이유를 묻고 근무를 대신 서고, 다친 사람에게 좋아하는 음식을
  가져다주고, 신입에게 지난 사고와 바뀐 수칙을 일러 주고, 고장 소문을 듣고 확인하러 간다. 그 기억이 회의에서 누구 말을 믿을지, 누구와 위험한 일을 할지에 걸린다.

진행 상황과 완성도 평가는 `docs/PROGRESS.md`, 앞으로의 순서는 `docs/ROADMAP.md`.

## 실행

1. **Godot 4.7.2 .NET 버전**을 설치합니다 (godotengine.org → Download → ".NET" 표시가 있는 쪽).
2. **.NET SDK 8 이상**을 설치합니다.
3. Godot 프로젝트 관리자에서 `game/project.godot`를 가져옵니다.
4. 오른쪽 위 망치 아이콘(Build)을 한 번 누른 뒤 실행(F5)합니다.

> Godot 버전이 다르면 `game/ShipSim.csproj` 첫 줄의 `Godot.NET.Sdk/4.7.2`를 설치한 버전으로 바꿔 주세요.

**배포 빌드 (v10)**: 에디터 메뉴 편집기 → 내보내기 템플릿 관리에서 4.7.2 **.NET** 템플릿을 받은 뒤, 프로젝트 → 내보내기 → `Windows Desktop` 또는 `Linux` → 프로젝트 내보내기.
명령줄로는 `godot --headless --path game --export-release "Windows Desktop" ../build/windows/ShipSim.exe`.
설정은 `game/export_presets.cfg`에 있습니다 (pck를 실행 파일에 넣음, x86_64). 개발 환경에 내보내기 템플릿이 없어 여기서 실제로 내보내 보지는 못했습니다.

**볼 만한 곳**
- 승무원 상세의 **판단** 탭: 모든 행동 후보의 점수와 이유. "왜 지금 이걸 하는지"가 보입니다.
- 아무것도 선택하지 않으면 **작업 목록**: 우주선이 올려 둔 일과, 누가 스스로 골라 맡았는지.
- **전력** 모드: 차단기가 내려가면 그 회로의 방만 어두워지고 빗금이 쳐집니다.
- **상태** 모드: 설비마다 마모(색)와 수명(막대).

- 사고를 일으킨 뒤 **방을 클릭**하면 외벽 상태, 환기 댐퍼, 격벽, 화재, 연기가 보입니다.
- **흔적** 모드 (v7): 벽마다 뚫린(빨강)·막은(노랑)·용접한(주황)·갈아 낀(파랑) 자국, 포기했던 방의 빗금, 불난 방의 그을음,
  사람이 쓰러진 곳(×)과 죽은 곳(+), 자주 고장 난 설비. **승무원을 고르면** 그 사람이 무서워하는 방이 보라색으로 물들고 전우와 선으로 이어집니다.
- 승무원 상세의 **기억** 탭 (v7): 침착함·긴장, 무서운 곳과 까닭, 함께 넘긴 사고와 전우, 지나온 일. 설비·방을 고르면 아래에 **이력**.
- **배관** 모드 (v9): 관마다 색(고온관 주황 · 분기 청록 · 귀환관 파랑 · 급수 하늘색), 흐르면 점이 움직이고, 밸브는 열림(초록)/잠김(빨강)/우회 중(노랑),
  새는 곳의 증기·물방울, 끊어진 곳 ✕, 임시 밀봉(노란 띠), 우회 배관(노란 점선). 냉각이 모자라면 원자로실·냉각실이 붉게, 물이 끊긴 수경재배실은 주황.
  상단 `냉각수·노심` 칸, 냉각실을 고르면 분기별 상태와 냉각 kW
- **구조** 모드 (v8): 연결부마다 아는 강도(검사 전이면 흐리게 "미확인"), 방마다 하중과 버틸 시간, 사출 준비 단계, 떨어져 나간 조각과 견인줄.

```
                                          (모자라면 우선순위 낮은 것부터 차단)
  냉각을 잃으면 SCRAM → 배터리 → (바닥나면) 보조 발전기를 손으로 → 펌프 → 원자로 재기동
  보조 발전기 연료도 없으면: 연료통 급유 / 채소 → 바이오 연료 / 제어봉 수동 인출 → 자연 순환 저출력(7kW) → 펌프 → 정상
  회로가 죽고 퓨즈가 없으면: 살아 있는 회로에서 임시 배선 (정격 넘기면 달아오름 → 탐 → 불)
  배터리가 빠지면: 사람이 D → C → B 순으로 회로를 내림 (A는 절대 안 내림), 여유가 생기면 되올림
산소 발생기 → 환기관(댐퍼) → 전기 들어오고 댐퍼 열린 방의 O2 보충·CO2 제거 ← 사람의 호흡, 불
공기 탱크 → 감압된 방 재가압 (다시 채울 수 없음)
정수기 → 물 탱크 → 재배대(생장등은 전기) → 수확 → 냉장고 → 조리대 → 배식기 → 식사
                                      └→ 남는 채소 → 작업대 → 필터·윤활유·바이오 연료
우주 공간 → 채집 장치(호퍼) → 원료 → 정제기 → 기본 수리재(금속판·구조재·케이블·전자재·퓨즈·실링폼, 탄소 필터·합성 윤활유)
                                      └→ 작업대 → 일반 부품(모터·펌프·베어링·전력 제어기·센서)
                                      └→ 희귀 소재 + 12시간 정밀 작업 → 고급 부품(원자로 제어부)
          얼음 → 정제기에서 녹임 → 공기 탱크·물 (공기 탱크가 처음으로 다시 찬다)
수리 연속선: 정상 수리 → 부품 제작 → Mk.1 임시품 → 20/60% 땜빵 → 부품 뜯기 → 구획 개조(임시 정비실·임시 침실) → 구획 포기
결정 (v7): 구획 포기·절전·뜯기·용도 변경·개조 → 급하면 지휘자 혼자(기관장 → 항법사 → 정비사 …), 아니면 회의 다수결
          → 성격·공포·근무지·침실에 따라 찬반, 부결되면 미뤘다가 압박이 커지면 다시, 반대한 사람은 서운함
역사 (v7): 사고 → 에피소드(위기가 시작되고 한 시간 조용하면 끝) → 수습 한 줄(대응자·잃은 것·쓴 것) → 함께 넘긴 사람끼리 유대·침착
          → 같은 사고를 여러 번 겪으면 교훈(실링폼 비축, 소화기 재충전법, 연료 비축)
진화 (v7): 평화 12시간 + 비상용 위로 남는 재료 → 겪은 사고가 가리키는 개조안 → 회의 → 보강판·배터리·예비 배선·소화 장치·Mk.3·제2 침실
기억 (v7): 감압·불길·쓰러짐 → 그 방이 무섭다(길찾기 비용, 일 기피, 악몽, 재개방 반대) → 한 달쯤 걸려 옅어짐 (그 방에서 지내면 빨리)
          중상·쓰러짐·동료의 죽음·과로 → 긴장(스트레스 기저치) → 몇 주
부품이 없으면: 덜 중요한 설비(엔진·콘솔 → … 포기한 구획의 설비부터)를 뜯어 부품을 꺼냄 → 그 설비는 멈춘 채 흔적으로 남음
소모품이 모자라면: 핵심 설비에만 쓰고 나머지는 임시 정비 (배급)
모든 설비: 마모 → (정비로 회복, 소모품 없으면 임시 정비) → 쌓이면 고장 확률 급상승 → 고장 → 경보 → 수리
외벽: 정상 → 찌그러짐 → 균열 → 미세 누출 → 파공 → (감압·격벽 잠금·댐퍼 폐쇄) → 실링폼 봉합 → 용접 수리
화재: 산소를 먹고 자람 → 연기·열·번짐 → 설비 고장·벽 약화·화상 → 감지(전기 있는 방만) → 소화기
구조 (v8): 거대 운석 → 연결부 손상 (+ 골조를 잃은 외벽 = 구조 연결 상실, 실링폼으로 못 막음) → 남은 연결부에 하중 → 피로 → 약한 것부터 끊김
          → 다 끊기면 방이 떨어져 나감 (벽이 찢기고, 열린 문으로 공기가 쏟아지고, 뜯긴 전선·배관·환기관, 사람은 밖으로)
          ↔ 검사(드론·EVA·삐걱거림)로 알아야 고친다 → 보강(구조재) · 골조 재건 · 임시 트러스
드론 (v8): 거치대 충전(전기) → 발진(에어락, 공기 탱크 조금) → 검사·보강·골조·트러스·견인 → 복귀 → 정비(부품) · 자재 보급(승무원)
          드론이 멈추면 → 승무원 EVA (우주복 산소 3시간, 느리고 무섭다) → 드론 수리
냉각 루프 (v9): 원자로 → 고온관 → 분기점 → (펌프 #1 → 방열판 #1) ∥ (펌프 #2 → 방열판 #2) → 귀환관 → 원자로
          관이 상하면 샌다(증기, 곁에 있으면 덴다) → 끊어지면 안 흐른다 → 냉각이 갑자기 줄면 노심이 달아오른다(350℃ 경고, 380℃ 과열 정지)
          냉각수 ← 정수 탱크의 물 (보충관, 끊기면 물통) ← 정수기(전기) · 얼음 → 냉각수가 30% 아래면 펌프가 헛돈다
          새는 관: 밸브 잠그기 (본관이나 마지막 분기면 "원자로를 세울까" 회의) → 새 관(금속판 2) / 실링폼 클램프 / 우회 배관 → 밸브 열기
          고칠 재료가 없으면: 엔진을 뜯어 금속판 / 새는 채로 다시 열고 냉각수를 부어 가며 (회의)
          임시 밀봉은 압력에 다시 터진다 → 금속판 둘이 모이면 계획 교체 (분기는 잠시 잠그고, 본관은 "원자로를 세울까" 회의) (v9.2)
급수 (v9): 정수기 → 급수 본관 → 수경재배대 (끊기면 물이 안 가고 36시간 뒤 말라 죽는다)
자동화 (v9.2): 주 컴퓨터(함교, 전기 2kW) → 격벽 자동 잠금 · 댐퍼 · 화재 경보 · 부하 우선순위 · 드론 관제 · 제어봉 빨리 내리기
          ↔ 환기(댐퍼 열림 + 생명유지실 전기 + 함교 기압)가 없으면 함교가 달아오른다 → 38℃ 넘으면 과열 정지 → 32℃까지 식어야 재시동
          멈추면 → 손으로: 격벽 돌려 닫기 · 댐퍼 열고 닫기 · 불은 눈으로 · 회로는 사람이 · 드론 복귀 · 제어봉 느림(시간당 22kW)
          드론은 사람이 거치대 콘솔에서 한 대씩 (끌어올 조각 → 밖의 일 → 검사) · 컴퓨터를 아예 잃으면 4시간 뒤 임시 제어 컴퓨터(전자재 2 + 케이블 2)
          → 교훈 "손 조작 훈련" · 개조 "예비 제어기"(배전실, 격벽·댐퍼·경보만)
문 구동기 (v9.4): 여닫을수록 닳음 · 운석 파편 · 옆 칸의 불 → 손으로 천천히, 감압 때 저절로 안 잠김 → 모터 / 케이블+금속판 임시 구동기
조명 (v9.4): 운석 · 불 → 캄캄한 방: 일 20% 느림(우주복 헬멧 등 제외) · 길에서 꺼림 · 오래 있으면 불안 → 케이블 1
저출력 운영 (v9.3): 원자로가 돌아도 수요를 못 댄 지 한 시간 → 회의 → 배전반에서 설비를 골라 내림
          (펌프 하나 · 산소 발생기 하나 · 빈 치료 침대 · 엔진 · 콘솔) → 재배대·조리·일하는 정제기를 앞줄로 → 전부 켜도 남으면 되돌림
사출 (v8): 버티지 못할 방 / 끌 수 없는 불 → 결정 → 대피 → 물품 회수 → 전력·배관·환기 차단 → 격벽 용접 → 연결 해제(드론·EVA, 아니면 폭발 볼트) → 사출
되찾기 (v8): 떠내려가는 방 → 회의 → 견인 드론(배터리가 모자라면 세워 두고 다시) → 계류 → 연결부 임시 고정 → 임시 도킹
          → 되살릴지 회의 (잔해면 부품만) → 연결부 보강 → 전력·배관·환기 재연결 → 다시 연다 ↔ 배전반처럼 대신할 게 없는 방은 무서워도 되찾는다
```

승무원은 명령을 받지 않습니다. 우주선이 **작업 목록**에 할 일을 올리면, 각자 기술·역할·거리·근무 시간·성격을 따져 스스로 맡습니다.
경보를 듣거나 방 공기가 나빠지면 10분 생각 주기를 기다리지 않고 **즉시 다시 판단**합니다.
길찾기는 "갈 수는 있지만 가기 싫은 곳"(저산소, 고온, 정전, 수동 문)에 비용을 매기고, 겁이 많을수록 크게 돌아갑니다.

**원칙**
- **시뮬레이션은 화면을 모릅니다.** `Core`에는 `using Godot`이 없습니다. 화면 없이 수십 일을 돌려 볼 수 있습니다.
- **틱 길이는 고정입니다.** 1틱 = 게임 2.4초, 게임 하루 = 1배속으로 20분. 전력·공기·마모는 15틱마다 계산합니다.
- **같은 시드면 같은 역사입니다.**
- **사건은 스크립트가 아닙니다.** 고장은 마모의 결과이고, 정전·공기 악화·굶주림은 시스템끼리 물려서 생깁니다.
  플레이어는 "처음 한 방"만 일으키고, 그다음(감압, 격벽, 정전, SCRAM, 발견 지연)은 전부 시스템이 굴립니다.

## 헤드리스 검사

```
dotnet run --project tools/Headless -- 30 7            # 30일, 시드 7
dotnet run --project tools/Headless -- 1 5 --scenario=o2
```

일반 실행은 하루 끝마다 식량·물·배터리·마모·고장·작업·부품을 보여 주고, 승무원별 식사·수면·작업·대화·정비·수리·수확·조리와
최저 포만감·기력·체력·혈중 산소를 점검합니다. 결정론도 확인합니다.

사고 시험(`--scenario=`)은 하루 돌린 뒤 사고를 일으키고 사흘을 보여준 다음 결과를 네 가지로 나눕니다 (처음 네 시간은 촘촘히).
`--scenario=all`은 전부를 한 줄씩, `--scenario=extreme`은 극단 시나리오만. `--death`를 붙이면 사망이 켜집니다.
관심 방의 기압·산소·연기·누출·잠금, 원자로·배터리·보조 발전기, 공기 탱크, 승무원 활동, 기록, 남은 물자.
- `o2` 산소 발생기 두 대 모두 고장
- `cooling` 냉각 펌프 한 대 고착 + 한 대 베어링 마모 (원자로 출력 제한 → 배터리 방전 → 부하 차단)
- `breaker` B 회로 단락 + D 회로 차단기 트립
- `meteor` / `bigmeteor` 작은 운석(수경재배실) / 큰 운석(창고)
- `powerhit` 큰 운석이 배전실로 → A 회로 → 냉각 펌프 → SCRAM
- `fire` 주방 화재, `combo` 큰 운석 + 주방 화재(정전으로 감지 지연)
- `blackout` 냉각 펌프 둘 고착 + 배터리 6% → 보조 발전기 → 재기동
- `injury` 정비사 부상 → 의무관 치료
- `chaos` 큰 운석 둘 + 화재 동시에
- `downed` 정비사가 창고에서 쓰러짐 → 업어서 의무실로
- 극단 (몇 개는 실패해야 정상): `nosuits` 우주복 두 벌뿐인데 두 구획 파공, `nosealant` 실링폼 두 개뿐인데 큰 파공 셋,
  `keycrew` 기관장·정비사 중상 + 냉각 펌프 고착, `nofuel` 보조 발전기 연료 2시간 + 배터리 바닥 + 펌프 고착,
  `overload` 운석 둘 + 화재 둘 + 고장 셋, `secondhit` 공기 탱크가 빈 채로 큰 파공
- 적응 (v5, `--scenario=adaptive`): `darkship` 배터리 0 + 보조 발전기 연료·연료통 없음 + 펌프 고착 → 원자로 수동 기동,
  `nofuses` 퓨즈 없이 A·B 회로 단락 → 임시 배선·콘솔 뜯기, `noparts` 예비 부품 없이 펌프 둘 고착 → 엔진 뜯기,
  `lostquarters` 실링폼 없이 침실 파공 → 침실 포기 → 휴게실 간이침대

재료 시나리오 (v6, `--scenario=materials`): `wreck` 냉각 펌프 파손 + 펌프 부품 없음 → 금속판으로 부품을 만들어 재건,
`noreactorctl` 원자로 제어부·희귀 소재 없음 → Mk.1 수동 제어기, `nomaterials` 재료 전부 없고 채집 장치 고장 → 뜯어 쓰기,
`lostworkshop` 정비실 포기 → 창고 임시 정비실, `noparts` 일반 부품·금속판 없이 펌프 고착 → 정제 → 제작

회복 리듬: `40 7 --rhythm=chaos` (하루 뒤 큰 사고 한 번 → 40일 평화. 공기 탱크·실링폼·금속판·부품·외벽 최대 강도·함선 지표가 날마다 어떻게 되돌아오는지)

물자 부족 장기 시험: `60 11 --scarcity` (하루 뒤 예비 부품·케이블·퓨즈·연료통을 바닥내고 필터·윤활유 6개만, `--every=10`일마다 무작위 사고).
하루마다 전력·물자·뜯긴 설비·임시 배선·절전·임시 침실·폐쇄 구역을 보여 주고, 끝에 무엇이 어떻게 바뀌었는지와 결과를 냅니다.
`SHIPSIM_LOGDAY=30` 이면 30일차부터 사흘의 기록과 남은 작업·방·설비 상태를 덧붙입니다.
